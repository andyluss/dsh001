# 实验 001 · 知识卡片（极简版）

> DSH 实验室 001 号的第一个独立实验。实验总览与新增实验的约定见根目录 [`../../README.md`](../../README.md)。
> 本目录自包含：`index.html`（原生版）、`react-app/`（React 版）、`viz/`（排序算法可视化）。
> 本实验的变更记录见 [`CHANGELOG.md`](CHANGELOG.md)。

一个零依赖的知识卡片管理程序，有两个实现版本，共享同一份本地数据
（localStorage 的 `kcards.v1` / `kcats.v1` / `ktags.v1`，两个版本可随时切换使用）。

| 版本 | 目录 | 说明 |
| --- | --- | --- |
| 原生版 | `index.html` | 单文件 HTML+CSS+原生 JS，双击即用，零依赖 |
| React 版 | `react-app/` | Vite + React 18，组件化，功能更全（复习、排序、拖拽、深色模式等），带 vitest 测试 |

## 功能

### 卡片

- 正面（问题/标题）+ 背面（答案/内容）
- 单击翻转卡片，卡片右下角 ✏️ 按钮编辑，右上角新建
- 全文搜索（覆盖正面、背面、分类名、标签名），Esc 清空
- 📌 置顶：卡片右上角图钉按钮，置顶卡片始终排在最前
- 排序：默认顺序 / 最近创建 / 最近更新 / 标题 A→Z / 标题 Z→A
- 复制：编辑弹窗中的「复制」一键生成新卡片

### 分类（树形）

- 左侧「📁 分类」树，任意层级
- 点节点筛选该分类**及其所有子分类**下的卡片；点箭头展开/收起
- 悬停节点行末：`＋` 添加子分类、`✎` 重命名、`✕` 删除（含子树，卡片关联自动清空）
- **拖拽调整层级**：按住节点拖到另一节点上（成为子节点）或拖到行上/下 1/4 区域（成为前/后兄弟）；禁止拖入自身子树

### 标签（树形关联）

- 左侧「🏷 标签」树，任意层级，标签之间可建立父子关系（同样支持拖拽调整）
- 一张卡片可挂多个标签（编辑卡片时按树形勾选）
- 点标签筛选卡片时，**包含所有子孙标签**下的卡片
- 卡片上的标签 chip、分类角标可直接点击筛选

### 复习模式（React 版）

- 基于简化 SM-2 算法的间隔重复：忘记/模糊/认识/简单 四档评分
- 顶部「复习 (N)」按钮显示到期数量，菜单可选「复习到期」或「复习全部」
- 复习弹窗：空格/回车翻面，`1`/`2`/`3`/`4` 快捷评分，Esc 退出，结束时展示评分统计
- 每张卡片记录 `ease / interval / reps / lapses / due`，到期自动进入复习队列

### 其它

- **撤销/重做**：顶部 ↩/↪ 按钮，快捷键 `Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`（在输入框内不拦截）
- **深色模式**：顶部 🌙/☀️ 切换，跟随系统偏好初始化，选择持久化
- 导出/导入 JSON（含卡片、分类树、标签树、复习进度）

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Esc | 关闭弹窗 / 清空搜索 |
| 空格 / Enter | 复习时翻面 |
| 1 / 2 / 3 / 4 | 复习时评分（忘记/模糊/认识/简单） |
| Ctrl/⌘ + Z | 撤销 |
| Ctrl/⌘ + Shift + Z | 重做 |

## 运行

**原生版**：直接用浏览器打开 `index.html`。

**React 版**：

```bash
cd react-app
npm install                 # 依赖（npm 缓存目录权限有问题时加 --cache ./node_modules/.npm-cache）
npm run dev                 # 开发服务器
npm run build && npm run preview   # 构建并预览产物（dist/）
npm test                    # vitest 单测（34 项）
```

## 数据

- `kcards.v1`：卡片数组（含 `categoryId`、`tags`(标签节点 id 数组)、`pinned`、`reviews`(SM-2 进度)）
- `kcats.v1`：分类树 `[{ id, name, children: [...] }]`
- `ktags.v1`：标签树（同构）
- `ktheme.v1` / `ksort.v1`：深色模式与排序偏好
- 旧版卡片的字符串标签会在首次加载时自动迁移为标签树节点
- 首次打开预置 3 张演示卡片与示例分类/标签树

## 技术

- 原生版：单文件 `index.html`，无任何外部依赖
- React 版：`react-app/src/store.js` 纯函数数据层（树操作、SM-2、排序、筛选，均可独立测试）+ 组件化 UI（App / Sidebar / Tree / CardGrid / CardItem / FilterBar / EditorModal / ReviewModal）
