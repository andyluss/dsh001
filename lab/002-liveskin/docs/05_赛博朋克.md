# 05 · 赛博朋克（Cyberpunk）

> 对应卷：`doc/punks/cyberpunk/`
> 家族 id：`CyberpunkFamily` · 建议 variant 数：4

---

## 一、分支速览

**一句话**：高科技，低生活。最尖端的界面与最破败的生活同框。

**核心张力（决定了皮肤要表达什么）**：这一卷的论点不是「复古未来」，而是**「过期未来」**——设定年份（2019 / 2020 / 2049）写死在标题里，时间一到，「预言」当场变成「账本」。四步遗产化（许诺 → 过期 → 入土 → 出土再消费）被压缩进同一代人的生命周期。

> **对皮肤的直接影响**：赛博朋克的未来感自带倒计时。质感里必须**同时有「许诺」与「墓碑」**——所以它不能是干净的霓虹，必须是**被霓虹照亮的破败**：光越多，越照见脏。

**时代底座**：信息纪。能源＝微电子与网络，界面＝键盘与 CRT 终端。器物：CRT 显示器、绿字终端、拨号网络、公用电话亭、磁带软盘、飞行车、全息广告、义体与后颈接口、反光太阳镜。

## 二、配色规格

来源：卷内给出的主色调为「品红、青与金属冷光」，天色与主光源为「雨夜霓虹的黑紫与色光」。**卷内未给色值**，以下为落地取值（标注为推断）。

| 语义 | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| 底 | `#120A1A` 深紫黑 | `#0B0410` 黑紫 | 页面底 |
| 面板 | `rgba(38,22,52,.78)` | `rgba(20,10,32,.82)` | 悬浮面 |
| 描边 | `#00E5FF` 20% | `#00E5FF` 26% | 冷光边 |
| 主光 A | `#FF2D95` 品红 | 同 | 强调、危险、激活 |
| 主光 B | `#00E5FF` 青 | 同 | 链接、选中、信息 |
| 点缀 | `#FF5A1F` 橙红 | 同 | 告警、高亮 |
| 终端绿 | `#39FF6A` | 同 | 代码块、终端类元素 |
| 正文 | `#EDE6F5` | `#E8DCF2` | 主文字 |
| 次要文字 | `#B49AC8` | `#A88FBE` | 说明、标签 |

**关键决策**：绿字终端（`#39FF6A`）**只用于代码块与等宽元素**，不做全局正文色——全局绿字是「终端模拟器」，不是赛博朋克。

## 三、材质与形式语言

- **雨幕糊光**：所有发光元素带大半径 bloom（`box-shadow` 多层扩散），**不是**锐利描边。
- **湿面倒影**：面板底部做极淡的竖向镜像渐变（`linear-gradient` 反向），暗示「地面是湿的」。
- **垂直分层**：顶栏干净冷色（资本层）／列表区霓虹浸染、贴边密集（街道层）。**用上下密度对比表达权力落差**，这是这一支最容易被忽略但最重要的一层。
- **圆角**：偏小（4–8px）。赛博朋克的形态是**切割**不是**流线**。
- **字体**：等宽用于数据与代码；标题可用拉丁展示字，但**不用**「未来感」无衬线大全写。
- **母题库**（可自由组合）：霓虹 / 雨 / 塔 / 义体 / 城寨 / 招牌。

## 四、家族参数

公共参数：`glass` / `blur` / `accent` / `intensity` / `motion`（语义见 `01_设计方法.md`）。

| key | type | 范围 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `neon` | number | 0–100 | 68 | 霓虹强度：bloom 半径与色光饱和度 |
| `rain` | number | 0–100 | 55 | 雨幕与倒影：噪点密度 + 面板底部镜像 |
| `scanline` | number | 0–100 | 35 | CRT 扫描线：细横纹透明度 |
| `tiering` | boolean | — | true | 垂直分层（顶栏冷／列表区密）是否开启 |

> `scanline` 默认压在 35——它是**氛围**不是**滤镜**。拉到 100 会显著影响可读性，这是有意的上限设计。

## 五、Variant 清单

### V1 · `RainyNeon` 雨夜霓虹（标准支）

- **场景**：最典型的赛博朋克。雨、招牌、巨企塔。
- **壁纸**：黑紫底 + 左上品红辉光 + 右下青辉光 + 中部极淡的垂直光带（模拟远处招牌的光柱），叠一层低透明噪点。
- **材质**：大半径 bloom、面板底部镜像、扫描线。
- **动效**：**霓虹呼吸**——`accent` 色的 bloom 以 8s 周期在透明度 0.85↔1 之间缓慢起伏（只动 `opacity`）。
- **defaults**：`{"glass": 52, "neon": 68, "rain": 55, "accent": "#FF2D95"}`

### V2 · `TerminalGreen` 绿字终端（技术残骸支）

- **场景**：卷内点出的「过期倒计时最省力的载体」——CRT、绿字、扫描线、成排屏幕。
- **壁纸**：纯黑 + 一层极淡的同心圆辉光（模拟 CRT 玻璃的反射）+ 较强的扫描线。
- **材质**：**方正**——圆角归零、边框用 1px 实线、无 bloom（荧光屏不发光晕），只有微弱的字符辉光。
- **动效**：**光标闪烁**——仅在等宽元素（代码块）上做 1.2s 方波闪烁。
- **defaults**：`{"glass": 22, "neon": 20, "scanline": 78, "rain": 8, "accent": "#39FF6A", "tiering": false}`

> 这一支是家族里**最克制**的：面板接近实色，适合写代码。

### V3 · `MegacityNight` 巨企塔（垂直分层支）

- **场景**：把「上下密度对比」推到极致。顶栏是资本高空，往下每深一层更脏更密。
- **壁纸**：三段垂直渐变（顶部深蓝黑 → 中部紫 → 底部品红浸染的暗红），加一层极淡的垂直条纹（模拟塔身）。
- **材质**：顶部面板用**冷色、细线、大留白**；底部面板用**暖色、粗边、密排**。同一个界面里出现两种密度。
- **动效**：**全息广告**——右上角一个极淡的横向扫描光带缓慢下移（`transform: translateY`，12s 周期，opacity 0.06）。
- **defaults**：`{"glass": 60, "neon": 82, "rain": 30, "tiering": true, "accent": "#00E5FF"}`

### V4 · `PostCyber` 后赛博（成熟网络支）

- **场景**：卷内列为 `postcyberpunk`——同底座但网络已成熟，主角是系统内的专业者，基调从「失控」转为「谨慎的乐观」。
- **壁纸**：无雨、无塔。深青灰底 + 顶部一条极淡的琥珀色地平线光。
- **材质**：相比 V1 减少 bloom 与噪点，增加**清晰的层次与留白**；圆角略大（8px）；用克制的青与琥珀代替对撞的品红青。
- **动效**：**数据流**——一条极细的青色线段沿面板顶边缓慢流过（`transform: translateX`，18s）。
- **defaults**：`{"glass": 72, "neon": 34, "rain": 0, "scanline": 0, "accent": "#4FD1C5"}`

> 这一支是「赛博朋克里能长时间工作的那一支」，也是给 D6 里「诊断而非气氛」留的位置。

## 七、雷区与规避

| 雷区 | 卷内依据 | 本项目的规避 |
| --- | --- | --- |
| **东方主义** | 东亚城市被剪影化成「未来之城」的背景板，只提供密集楼宇与招牌的异域质感，很少成为叙事主体 | **不使用汉字 / 日文招牌**。若需要招牌质感，用无意义的字形块或纯几何色块，不做伪文字 |
| **洗白与功能位** | 多样性缺席是明确雷点 | 皮肤不涉及人物，无需处理；但**不使用**「终端女孩」式的视觉隐喻 |
| **犬儒化** | 反乌托邦视觉成为时尚商品后，只剩「很酷的绝望」 | V4 `PostCyber` 就是给这条留的位置：**给出分析而非仅仅给出气氛** |
| **霓虹滥用** | — | 霓虹只做强调，不做底色。底色永远是暗的 |

## 八、材质签名（不可互换的那一件事）

> 把界面缩成 64×64 去掉颜色，仍能认出是赛博朋克：

**雨幕的糊光 + 面板底部的竖向倒影。**
换色换不出来——它是「光被水改变了形状」这件事本身。
