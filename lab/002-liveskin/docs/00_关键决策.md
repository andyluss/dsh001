## D1 · 本轮做几个家族

| 选项 | 内容 | 代价 |
| --- | --- | --- |
| A | **五个 P0 分支全做**（蒸汽 / 柴油 / 原子 / 赛博 / 生物） | 约 20 支皮肤，工期最长，但一次成型 |
| B | 先做 2 个样板（赛博朋克 + 蒸汽朋克），确认观感后再铺开 | 快，能尽早校准方向；但中途改风格语言会返工 |
| C | 五个 P0 + 两个 P1（+ 磁带未来主义 + 太阳朋克） | 七个家族，约 28 支 |

**建议 A**。理由：分支之间共享工程骨架（`01_设计方法.md` 里的三层映射），一次做完的边际成本远低于分两轮——第二轮要重新进入状态。若你希望先看效果，B 也合理，选它我会把赛博朋克做成「可复制的模板」。

---

## D2 · 每个家族做几支皮肤

| 选项 | 每家族 | 合计（5 家族） |
| --- | --- | --- |
| A | **4 支** | 20 支 |
| B | 3 支 | 15 支 |
| C | 5~6 支 | 25~30 支 |

**建议 A（每家族 4 支）**。4 支是「能覆盖一个分支的主要取向、又不至于互相重叠」的甜点：通常可以分成「最典型的一支 + 最克制的一支 + 一个极端场景 + 一个跨媒介取向」。3 支会缺一个维度，6 支开始出现换色充数。

---

## D3 · 明暗两套怎么做

| 选项 | 做法 |
| --- | --- |
| A | 每支皮肤都做**完整双套**（亮/暗各一套独立配色，同等表现力） |
| B | **每支以分支天性定主调**，系统切到另一侧时做「降级适配」——保证不刺眼、对比达标，但不追求同等表现力 |
| C | 一律固定单套，不跟随系统 |

**建议 B**。理由：分支天性差异很大——赛博朋克、磁带未来主义、生物朋克**本来就是深色的**，硬做一套浅色版只会得到「被漂白的赛博朋克」；而蒸汽朋克、原子朋克、太阳朋克天生偏亮。强行对称会稀释每支的性格。B 让主调充分表达，同时保证系统切主题时不崩（工程约束 C4 仍然对两侧都生效）。

---

## D4 · 要不要分支外延

| 选项 | 家族数 | 内容 |
| --- | --- | --- |
| A | 5 | 只做 `doc/punks/` 覆盖的五卷 |
| B | 6 | + **磁带未来主义**（`CassetteFuturismFamily`） |
| C | 7 | + 磁带未来主义 + **太阳朋克**（`SolarpunkFamily`） |

**建议 C**。理由有二：

1. **磁带未来主义有卷内依据**——赛博朋克卷把它作为对照项讨论，并明确指出「与赛博朋克的边界本质是布光与气氛的边界」。它的物质底座（米白塑料机箱、荧光绿单色终端、机房日光灯）与赛博朋克完全不同，够格独立。
2. **太阳朋克补的是光谱上缺的那一格**。五卷设想的未来**全部可疑**（阶级、威权、双面核能、不平等、身体商品化）。整套收藏缺一个**可向往的未来**，缺了它，情绪是单色的。代价是它没有卷内依据，只能靠外部资料，我会在规格文档里标明哪些是外部推断。

选 A/B 也完全可以——见 `09_分支外延评估.md` 的逐项评估。

## D5 · 动效做到什么程度（**已定，除非你反对**）

**决定：每支皮肤一个标志性动效，默认开启，由公共参数 `motion` 可关。**

不采用「全部静态」（朋克美学的一半在动态：扫描线、蒸汽、脉冲、雨滴），也不采用「堆满动效」（工程约束 C5 规定只用合成属性，且无限循环的合成层上限 2 个）。每支只给一个，反而更能形成识别度。

---

## D6 · 历史雷区怎么处理

`doc/punks/` 里三卷明确点出了雷区：

- **柴油朋克**：酷法西斯——把法西斯时代的机械、建筑、制服抽离意识形态当风格欣赏。卷内判据是「看挪用是否冒犯一种秩序」。
- **赛博朋克**：东方主义——把东亚城市剪影化成异域背景板，只借招牌街景不把亚洲当叙事主体。
- **原子朋克**：受害者缺位——蘑菇云当纯装饰，广岛长崎、比基尼环礁、下风向居民与铀矿工人在画面里消失。

| 选项 | 做法 |
| --- | --- |
| A | **视觉上规避敏感符号 + 在皮肤描述里写明历史坐标** |
| B | 纯美学，不表态 |
| C | A + 在皮肤里显式加入「历史坐标」视觉元素（档案编号、年份戳记、受害者可见） |

**建议 A**。具体规避：

- 不使用可识别的纳粹 / 法西斯符号（鹰徽、卐字、党卫队符文、领袖崇拜式构图）；
- 汉字霓虹招牌**不当作异域贴纸**——要么不用文字，要么用无意义字形块（避免伪中文）；
- 蘑菇云不做纯装饰图案；若出现，必须与「受害者可见」同框。

**不选 C 的理由**：C 的立场更彻底，但它把「皮肤」变成了「展板」。LiveSkin 的皮肤是给人长时间盯着工作的界面，不是一次性的观念作品。历史坐标写在**描述文档**里比刻在界面上更持久，也更不容易被当成装饰消费掉。

## D7 · 实现顺序

| 选项 | 顺序 |
| --- | --- |
| A | **按时代轴**：蒸汽 → 柴油 → 原子 → 赛博 → 生物 →(磁带 → 太阳) |
| B | 赛博朋克先行（视觉最明确、最好验证） |
| C | 按 `doc/punks/` 卷序：原子 → 生物 → 赛博 → 柴油 → 蒸汽 |

**建议 A**。理由：时代轴就是 `09_分支外延评估.md` 里那条「可疑的未来 → 可向往的未来」的光谱，面板里的家族顺序也按它排。按轴推进能让相邻两支的差异被连续检验（做完蒸汽立刻做柴油，「同一个 20 世纪的两种想象」的对比最锋利），也最早暴露「材质签名不够不可互换」的问题。
