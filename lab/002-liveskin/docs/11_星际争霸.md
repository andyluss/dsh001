# 11 · 星际争霸：三个种族

> 本文是 `StarCraft` 系列三个种族皮肤的规格。**设计先行**：先在这里定下配色、材质与变体，
> 再动 CSS。
>
> **依据声明**：本系列**没有任何卷内资料**（`doc/punks/` 五卷不涉及游戏），全部由外部观察推断。
> 更重要的是：所有皮肤都是**纯 CSS 的美学演绎** —— 零外部资产（工程约束 C8 禁止 `url()` 与
> `@import`）、不出现阵营徽标与任何商标图形、不向界面注入文字（C9）。颜色、材质与光照语言
> 按种族的视觉特征提炼，不复制任何美术资源。

## 一、为什么这三个种族值得做成皮肤

七个朋克家族是一条**时间轴**（蒸汽 → 柴油 → 原子 → 赛博 → 生物 → 磁带 → 太阳），
它们问的是「我们曾经怎样想象未来」。三个种族问的是另一个问题：

| 种族 | 一句话 | 与现有家族的关系 |
| --- | --- | --- |
| 人族 Terran | 被流放的囚犯后代，用铆钉和胶带把旧联邦的破烂拼成能用的东西 | 最接近柴油朋克，但**少了那份浪漫**——柴油朋克的硬光是戏剧性的，人族的硬光是维修灯 |
| 虫族 Zerg | 不是「造」出来的，是**长**出来的；没有一件东西是设计过的 | 与生物朋克同源但更极端：生物朋克还在实验室里，虫族已经把实验室吃掉了 |
| 神族 Protoss | 古老、精密、几乎不落地；技术已经变成仪式 | 与太阳朋克同为「可向往」，但太阳朋克是**社区的**乐观，神族是**贵族的**庄严 |

**它们不补进时间轴**，而是作为一组「同一宇宙里的三种文明形态」并列。
面板里排在七个朋克家族之后，编号 11（`docs/` 里的序号）。

## 三、材质与形式语言

沿用「把界面缩成 64×64 去掉颜色仍能认出来」的判据（`01_设计方法.md` 第六节）。

| 家族 | 材质签名（去色后仍成立） | 与现有家族的区分 |
| --- | --- | --- |
| 人族 | **1px 内嵌亮边的铆接板缝 + 一层仪表扫描线** | 与柴油朋克的分界在**光的方向**：柴油朋克是单侧硬光切出的明暗面，人族是**均匀的顶灯**——维修灯不为戏剧性服务 |
| 虫族 | **没有一条直线：四角不等的大圆角 + 向内汇聚的湿润高光** | 与生物朋克的分界在**边界**：生物朋克是培养皿（有边框、有玻璃），虫族没有边界——高光向内收，像甲壳内壁的反光 |
| 神族 | **不模糊的锐利辉光 + 悬浮的金色细线** | 与赛博朋克的分界在**锐利度**：赛博朋克是雨幕糊开的 bloom，神族是**没有一丝模糊**的辉光；与太阳朋克的区分在光的方向：太阳朋克有太阳，神族的光**没有来源**（悬浮自发光） |

**光照方向轴**至此扩展为九个位置：线（蒸汽）→ 面（柴油）→ **顶灯（人族）**→ 反射（原子）
→ 向外 bloom（赛博）→ **锐利无模糊（神族）**→ 向内（生物）→ **无边界向内（虫族）**
→ 零位（磁带）→ 太阳（太阳朋克）。

## 四、家族参数

三个家族共用同一套参数**骨架**（与其它家族一致：材质 / 氛围 / 动效三组），
但种族专属的那个旋钮不同：

| 家族 | 专属参数 | 含义 |
| --- | --- | --- |
| 人族 | `scanner` | 仪表扫描线的强度。0 = 干净的现代平板 |
| 虫族 | `creep` | 菌毯纹理的密度。0 = 光滑甲壳 |
| 神族 | `psionic` | 灵能辉光的强度。0 = 熄灭的古代装置 |

外加共有的 `glass` / `blur` / `accent` / `intensity` / `motion`，共 8 个参数，
与其它家族数量一致；每个家族三档预设（`restrained` / `standard` / `cinematic`）。

## 六、决策点

1. **三个种族做成三个家族**（而不是一个家族挂九个小类）：家族层承载「共享的参数与调色板」，
   而三个种族的材质语言几乎没有共同点，塞进一个家族会让基层 CSS 变成空壳。
2. **每族四个变体而非三个**：三支很难覆盖「标准 / 偏亮 / 偏暗 / 极端」四个象限，
   而两档约定要求每个变体都要能在亮暗两侧都成立 —— 四个才够把这条轴铺开。
3. **不补进朋克时间轴**：它们是同一宇宙里的三种文明，不是时间轴上的位置。
4. **暗色档不做「降级适配」而做真正独立的调色板**：C12 要求两档都成立，
   照搬亮色值压深会得到一堆 1.x:1 的对比度（这正是 1.0 修掉的那批缺陷）。
