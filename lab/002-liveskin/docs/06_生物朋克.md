# 06 · 生物朋克（Biopunk）

> 对应卷：`doc/punks/biopunk/`
> 家族 id：`BiopunkFamily` · 建议 variant 数：4

---

## 一、分支速览

**一句话**：硅对碳的湿件朋克。把赛博朋克的「芯片与金属义体」换成「基因与器官」，延续「高科技低生活」的基调。

**判别器（卷内给出）**：① 技术符码必须是生物学的（基因、细胞、器官），不是芯片与电路；② 生物改造必须构成社会经济权力结构的中轴（基因专利、基因分层、生育与身份商品化）。

**核心张力（决定了皮肤该怎么做）**：

> **这一支是「最不怀旧」的**——素材是当下的细胞与基因，写的是「现在的下一格」。它的复古只落在**母题层**（回收「造人恐惧」），**不在视觉层**，所以卷内明确说它**「没有时代脸」**。

这条对设计的影响是决定性的：**生物朋克不能靠年代做识别**。蒸汽朋克有黄铜与铆钉，赛博朋克有霓虹与雨夜，生物朋克没有对应的「年代贴纸」。它的识别必须来自**材质本身的对立**——**碳的湿润 vs 硅的干燥**。

**命名状态**：卷内明确指出 biopunk **无公认原点**，`ribofunk` 归于保罗·迪菲利波（结集约 1996，**存疑**），biopunk 一词约 1990 年代末至 2000 年代流通（**存疑**）。本卷为中文语境首次系统化整理，全卷按「约／存疑」降档行文。

**时代底座**：能源不更换，只更换浪漫对象——**生命本身**。器物：培养皿、移液器、离心机、生物反应器、洁净室。城市：温室、生物穹顶、有机建筑。

## 二、配色规格

**卷内未给出任何色值**（hex / RGB / 色号皆无），只有色相级记述：「实验室的白／玻璃／液体」，「光源为培养皿冷光、荧光绿」。以下落地取值为**外部推断**。

| 语义 | 取值 | 用途 |
| --- | --- | --- |
| 底（洁净侧） | `#EFF4F2` 冷白 | Cleanroom 底 |
| 底（肉质侧） | `#14100F` 暗棕黑 | Fleshgarden 底 |
| 面板 | `rgba(255,255,255,.62)` / `rgba(40,28,26,.78)` | 两侧 |
| 培养皿冷光 | `#7FE8D8` | 环境辉光、描边 |
| 荧光绿 | `#5BFF9E` | **唯一强调色**（accent） |
| 组织 | `#7A3B3B` 暗红棕、`#B9786F` 肉粉 | 肉质侧的面板与底纹 |
| 黏液高光 | `rgba(220,255,240,.5)` | 柔边高光 |
| 正文 | `#10201E` / `#E8F5F0` | 两侧 |

**关键决策**：**荧光绿是唯一强调色**。卷内的光源语汇只有「培养皿冷光」与「荧光绿」两者，不要引入霓虹粉／紫（那是赛博朋克侧，卷内明确排除「义眼、霓虹雨」）。

## 三、材质与形式语言

- **湿润**：核心质感。阴影用**柔和内发光**而非硬边高光；面板边缘给一道半透明的「膜」——`inset 0 0 12px rgba(220,255,240,.35)` 这一类的内发光，而不是 1px 亮边。
- **圆角**：**不等**。洁側用规整的中等圆角（10px）；肉质侧用**不一致**的圆角（每个角不同值），暗示生长的不规则。
- **三色语汇「白／玻璃／液体」**：玻璃用半透明描边 + 模糊 + 青色折射；液体用缓慢的渐变位移（`hue-rotate` 不用，用透明度与位置的缓慢变化）。
- **符号系统**：双螺旋、碱基条带、核型——卷内明确它们是这一支的「齿轮与 logo」。这是唯一被允许的图形语言。
- **字体**：卷内**未涉及**。落地选择：正文用系统默认（保持可读），数据与序列用等宽。

## 四、家族参数

公共参数：`glass` / `blur` / `accent` / `intensity` / `motion`。

| key | type | 范围 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `wetness` | number | 0–100 | 60 | 湿润感：内发光的强度与高光的柔度 |
| `pulse` | number | 0–100 | 40 | 生物脉冲：呼吸式明度起伏的幅度（0 = 完全静止） |
| `membrane` | number | 0–100 | 55 | 膜层：面板边缘的半透明内发光厚度 |

> `wetness` 是这一支的主控参数——它直接对应「碳的湿润」这个不可互换的签名。

## 五、Variant 清单

### V1 · `Cleanroom` 洁净室（实验室洁净系）

- **场景**：卷内明列的第一个语汇簇——白／玻璃／液体、培养皿冷光、基因扫描界面。影像原型上溯 1931 年《弗兰肯斯坦》的实验室。代表《千钧一发》。
- **壁纸**：冷白底 + 顶部一片极淡的青绿辉光（培养皿的冷光）+ 一道横向的玻璃反光带。
- **材质**：**三分式**——冷白底 / 玻璃隔断（半透明描边 + 模糊）/ 液体（缓慢的渐变位移）。无噪声、无做旧。
- **动效**：**液体位移**——壁纸中的液体层以 20s 周期做极缓慢的位移（`transform: translateY`，幅度 2%）。
- **defaults**：`{"glass": 62, "wetness": 34, "pulse": 18, "membrane": 70, "accent": "#2FBFA8"}`

> 家族里最亮、最克制的一支。适合白天长时间工作。

### V2 · `Fleshgarden` 肉质花园（肉质共生系）

- **场景**：卷内明列的第二个语汇簇——组织、膜、根须、黏液；建筑长肉、机械生藤。
- **壁纸**：暗棕黑底 + 三团模糊的暗红径向渐变（不规则的团块）+ 极淡的纤维状纹理（极密的斜向 1px 条纹，透明度 0.04）。
- **材质**：湿润内发光、不相等圆角、面板边缘的膜层最厚。**没有一条硬边**。
- **动效**：**生物脉冲**——整个界面的亮度以 7s 周期在 `--ls-pulse` 控制下缓慢起伏（只动 `opacity` 于一层覆盖层，不影响文字）。
- **defaults**：`{"glass": 44, "wetness": 82, "pulse": 55, "membrane": 78, "accent": "#5BFF9E"}`

> 最浓的一支。`pulse` 默认 55，但**可以用滑杆压到 0** 得到完全静止的肉质界面。

### V3 · `Helix` 螺旋（基因符号系）

- **场景**：卷内明列的第三个语汇簇——双螺旋、碱基条带、核型充当 logo 系统。这是唯一被文档认可的图形语言。
- **壁纸**：深青灰底 + 一条纵向的双螺旋（用重复的径向渐变点阵模拟碱基对）+ 极淡的水平条带。
- **材质**：**符号化**——分隔线用「碱基条带」（`repeating-linear-gradient` 的四色细段），进度类元素用核型式的分段条。面板保持哑光，减少湿润感。
- **动效**：**螺旋旋转**——壁纸中的双螺旋以 60s 周期极缓慢地绕竖直轴旋转（`transform: scaleX` 在 -0.85↔0.85 之间往复，模拟 3D 旋转，仍是合成属性）。
- **defaults**：`{"glass": 56, "wetness": 40, "pulse": 22, "membrane": 45, "accent": "#5BFF9E"}`

### V4 · `Chimera` 嵌合（身体恐怖系 / 全家族最浓）

- **场景**：卷内明列的第四个语汇簇——表皮增生物、嵌合、多肢、器官外置。母本《变蝇人》（1986）。
- **壁纸**：近黑底 + **两个不同色温的光源**在对角线方向对撞（一角冷青、一角暗红）+ 一层不规则的噪点。
- **材质**：**异质**——同一个界面里出现**不一致的圆角与描边宽度**（部分面板 6px、部分 14px），模拟「不是同一批长出来的」。
- **动效**：**双心搏**——两个不同周期的明度脉冲叠加（5.5s 与 8.5s），产生不整齐的节律（只动 `opacity`）。

> ⚠️ **尺度约束**：这一支是「异质与不整齐」，**不是血腥**。不使用具象器官、体液、血肉纹理的写实表现。卷内批评明确指出「把恐惧浪漫化为末世寓言」是一个应当避免的方向——这一支做的是**陌生感**，不是惊吓。

- **defaults**：`{"glass": 38, "wetness": 76, "pulse": 68, "membrane": 60, "accent": "#8CF0C0"}`

## 七、雷区与规避

卷内点出的五条，逐条给本项目的做法：

| 雷区 | 卷内依据 | 本项目的规避 |
| --- | --- | --- |
| **优生学阴影** | 二十世纪优生学以「择优改造」之名行歧视与强制之实，含强制绝育乃至种族清洗；判别标准是把它摆上审判台，还是当作前提复述 | **不做「择优 / 完美 / 升级」的视觉隐喻**。不使用「进化阶梯」「优劣对比」「完美婴儿」式的图形 |
| **生物决定论** | 把行为、智力、健康还原为序列的必然输出，长期充当性别与种族歧视的论证工具 | 双螺旋 / 碱基 / 核형**只作装饰性图形**，不承载「读取即真相」的叙事。不使用「扫描结果判定等级」式的 UI 隐喻 |
| **两极浪漫化** | 把技术浪漫化为万能（永生、超人），或把恐惧浪漫化为末世（超级病毒、失控变异、优生暴政），两者都脱离真实基因技术缓慢、不确定的节奏 | 动效一律**缓慢**（7s 以上的周期）。**不做**「突变爆裂」「病毒扩散」式的急促动画 |
| **标签通胀** | 丧尸病毒、异形怪物、环保突变都被称作生物朋克 | 本家族**不出现**丧尸、怪物、异形的视觉母题 |
| **硅／碳一刀切** | 义体、神经接口、纳米机械游走硅碳之间 | 不刻意与赛博朋克划清界限；两者共处一条光谱，差异由**材质签名**承担而非口号 |

**关于卷内「文档未涉及」的部分**：字体排印、具体材质参数、平面设计参考，卷内都没有。本规格中标注为**外部推断**的部分（色值、字体选择、动效周期）属于实现决策，不声称有卷内依据。

## 八、材质签名（不可互换的那一件事）

> 把界面缩成 64×64 去掉颜色，仍能认出是生物朋克：

**没有一条硬边，且所有高光都向内发光。**

赛博朋克的高光是**打上去的**（bloom 向外扩散），蒸汽朋克的高光是**磨出来的**（沿金属边），生物朋克的高光是**从材料里透出来的**——面板的边缘是一圈柔和的、半透明的膜，而不是一条亮线。这一个区别就足以把三支分开。
