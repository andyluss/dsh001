# LiveSkin · 复古未来朋克皮肤家族（设计文档集）

> 本目录是**动手实现之前**的设计文档。目标：为 `doc/punks/` 收录的每一个复古未来朋克分支，各做一个 LiveSkin 皮肤家族。
> 状态：**实现中**。范围 = **7 个家族 × 4 支 = 28 支皮肤**；顺序 = 按时代轴。
> 进度：**6 / 7 家族完成**（蒸汽 / 柴油 / 原子 / 赛博 / 生物 / 磁带，共 24 支已上线并过全部自动检查）。
> 决策记录见 `00_关键决策.md`。

## 一、这套文档要解决什么

LiveSkin 已经把「皮肤」做成了三级模型：**family（大类）/ variant（小类）/ preset（档位）**。

朋克资料天然也是分层的，两边几乎一一对应——**但对应关系不是显而易见的**，需要一条判据：

> **判断两个东西是同一个 family 还是不同 family，看的是「时代的物质底座」是否相同**（能源、材料、界面器物三者），不是「感觉像不像」。

这条判据直接决定了几个容易做错的地方：装饰朋克与柴油朋克**共用战间期的 Art Deco 都会与同一批世博会档案** → 同一个 family；磁带未来主义与赛博朋克**共用 80 年代的技术想象但器物完全不同** → 不同 family。详见 `01_设计方法.md`。

**分类就是面板里的行**。`family.json` 的 `category` 决定它落在哪一行，`order` 决定类内顺序；
行序由宿主常量 `CATEGORIES` 给出（`朋克美学` → `千禧美学` → `星际争霸`）：
七个朋克家族组成时间轴，千禧年美学紧挨着它的右端（Aero 是这批可疑未来全部落空之后、
企业给出的最后一次乐观），星际争霸三族不在轴上，单独一行。
分类漏写或写错会被 linter 直接报错，不会悄悄混进别的行。

**七个朋克家族合计 28 支，全部落地。** 顺序即实现顺序，也是面板里的家族排序。

第 8–10 行是**星际争霸的三个种族**，规格见 [`11_星际争霸.md`](11_星际争霸.md)。
它们不在朋克时间轴上，问的是另一个问题（同一宇宙里的三种文明形态），见第四节。

第 110–160 行是**千禧美学**的六个家族，规格见 [`12_千禧美学.md`](12_千禧美学.md)。
它们按血缘与年代排：孟菲斯（祖先）→ 网页 1.0 → Y2K → Frutiger Aero → McBling（旁支）→ 中文千禧（地方线）。

+ 3 个种族家族 12 支。**类内顺序不再是家族 id 的字母序** —— 朋克类按光谱轴序、
千禧类按血缘年代序、星际类按种族序，由每个家族的 `order` 决定。

每个家族的 variant 清单、配色表、参数、动效、雷区处理，见对应规格文档。

## 四、光谱：这套收藏的骨架

单独看，这是七个皮肤；连起来看，这是**一条关于「我们曾经如何想象未来」的时间轴**。

```
可疑的未来 ←─────────────────────────────────────────────→ 可向往的未来

生物朋克    赛博朋克    原子朋克    柴油朋克    蒸汽朋克   磁带未来主义   太阳朋克
身体商品化   不平等     双面核能    威权档案    阶级回望    怀旧机房      社区共生
  （湿件）   （信息）    （原子）    （内燃）    （蒸汽）    （微电子）    （可再生）

时代底座：近未来 ←──────────────────────────────────→ 19 世纪
          原子朋克 1945—1969 ｜ 柴油朋克 1918—1945 ｜ 蒸汽朋克 1837—1901
```

**这张图本身是一个产品事实**：面板里的家族顺序应当按它排列，README 里也应当这样介绍。用户在家族列表里看到的不是七个皮肤，而是一条光谱。

**两个值得注意的位置**：

- **生物朋克在轴上最靠左**——卷内明确指出它「最不怀旧」，素材是当下的细胞与基因。它的复古只在母题层，**视觉上没有年代脸**。所以它是唯一一支**不能靠年代做识别**的，只能靠材质（碳的湿润 vs 硅的干燥）。
- **太阳朋克在轴上最靠右**，而且**它是唯一一支设想的未来不可疑的**。其余六支（含生物朋克）设想的未来都带着各自主张的伤口。缺了它，这套收藏在情绪上是单色的。

**星际争霸的三个种族不在这条轴上。** 它们不是「曾经的未来」，而是同一个宇宙里的三种文明形态：
人族把它**拼**出来，虫族把它**长**出来，神族把它**想**出来。硬要放，人族最靠近柴油朋克
（工业、尘埃、实用主义），虫族最靠近生物朋克（有机、无边界），神族则在这条轴的右端之外 ——
它设想的技术已经变成仪式，不再是「未来」而是「永恒」。并列而不排进轴里，
是为了不让这条时间轴被稀释成「一堆科幻主题」。

**已有的 `FrutigerAeroFamily` 在这张图上的位置**：它在最右端之外——Aero 不是朋克，它是这批可疑未来全部落空之后、企业给出的那份**最后一次乐观**（2004—2013）。把它与太阳朋克相邻排列，两者的对照（企业的乐观 vs 社区的乐观）本身就很说明问题。

## 四之二、材质签名登记

> 判据见 `01_设计方法.md` 第六节：把界面缩成 64×64 **去掉颜色**，仍能认出是哪个家族。
> 每落地一个家族就在此登记它那一件「换色换不出来」的东西——这是防「七个家族互相抄」的唯一机制。

| 家族 | 材质签名（去掉颜色后仍然成立） |
| --- | --- |
| `SteampunkFamily` | **高光只沿金属边缘走，平面上什么都不留**（磨出来的） |
| `DieselpunkFamily` | **硬边的明暗边界 + 可见的胶片颗粒**（切出来的；颗粒是底色不是滤镜） |
| `AtompunkFamily` | **干净的瓷釉平面上，一道硬边的镀铬反光带**（七支里唯一完全不做旧） |
| `CyberpunkFamily` | **雨幕的糊光 + 面板底部的竖向倒影**（七支里唯一向外 bloom 的一支） |
| `BiopunkFamily` | **没有一条硬边，所有高光都向内发光**（**向内**，与赛博朋克的**向外**正好相反） |
| `CassetteFuturismFamily` | **平坦的哑光色块 + 1px 内嵌亮边**（注塑件倒角的反光，不是磨出来的） |
| `SolarpunkFamily` | **不等圆角 + 编织纹理**（手作、非模具；七个家族里唯一的光源是太阳本身） |
| `TerranFamily` | **1px 内嵌亮边的铆接板缝 + 一层仪表扫描线**（均匀顶灯，没有明暗面） |
| `ZergFamily` | **没有一条直线：四角不等的大圆角 + 向内汇聚的湿润高光**（没有边界） |
| `ProtossFamily` | **不模糊的锐利辉光 + 悬浮的金色细线**（光没有来源） |
| `MemphisFamily` | **1px 黑描边 + 大块几何图案印在层板上**（图案是印刷，不是光影） |
| `WebcoreFamily` | **刻意低精度：1px 双色立体边框 + 抖动网点**（唯一一支「分辨率不够」是设计意图） |
| `Y2KFamily` | **硬边镀铬高光带 + 果冻的内透光**（有棱角的透明，与 Aero 的无棱角相对） |
| `McBlingFamily` | **高密度亮片颗粒 + 缎面渐变**（亮片是颗粒反光，不是玻璃透光） |
| `ChineseY2KFamily` | **CRT 扫描线 + 冷白光管**（网吧里日光灯是唯一光源，屏幕是唯一暖色） |

**已实现的对照**：

- 蒸汽朋克的光*沿边缘走*（一条**线**），柴油朋克的光*把画面切成两半*（一个**面**）——相邻两支，去掉颜色也不会认错。
- 柴油朋克**浮在一层胶片颗粒上**，原子朋克**一点噪点都没有**——同样是战间期到战后这段相邻的历史，一个是被重新打光的旧档案，一个是刚出厂的整体注塑件。「做旧」与「不做旧」本身就是最强的分界。
- 光的方向是完整的一轴：蒸汽朋克沿边缘走（**线**）→ 柴油朋克切出硬边（**面**）→ 原子朋克在镀铬上反照（**反射**）→ 赛博朋克**向外扩散**并被水揉糊（**bloom**）→ 生物朋克**向内透出**，是膜不是灯泡（**inward**）。五支相邻的家族，去掉颜色后只靠「光怎么走」就能分开；而赛博朋克与生物朋克的方向**正好相反**，放在一起看这一轴才闭合。

- 磁带未来主义补上的是轴的**零位**：它**根本没有方向性光源**。机房日光灯是均匀的，没有明暗落差、没有 bloom、没有暗角 —— 其他六支的光都能被指出「从哪里来」，只有它不能。

  这条轴有两个可自动核验的侧面：生物朋克四支的面板阴影里「向外扩散」的条数为 **0**；磁带未来主义四支的面板阴影里「大半径外向模糊」的条数同样为 **0**。

- 太阳朋克是这条轴上**唯一的光源可以被指名的一支**：其余六支的光都能被指出「从哪来」，但那个"哪"是抽象的（边缘、平面、镀铬、雨幕、膜、日光灯）。太阳朋克的光有实际方向、温度和时刻——`dawnlight` 的整块背景就是一道低角度暖色渐变。它同时是唯一一支**允许不精确**的：`craft` 参数把圆角做成四个角互不相等，这是手作而不是模具的证据，与原子朋克/磁带未来主义那种"整体注塑件"的精确正好对立。

  **这条轴到此闭合成七个位置**：线（蒸汽）→ 面（柴油）→ 反射（原子）→ 向外 bloom（赛博）→ 向内（生物）→ 零位（磁带）→ 太阳（太阳朋克）。去掉颜色，七个家族仍能只靠「光怎么走」两两分开。

- 三个种族把这条轴**从七个位置扩到九个**，插入的两个位置都在已有两支之间：
  **人族的均匀顶灯**补在「面」（柴油）与「反射」（原子）之间 —— 柴油朋克的硬光是为戏剧性服务的，
  人族的顶灯只为让人看清；**神族的锐利辉光**补在「向外 bloom」（赛博）与「向内」（生物）之间 ——
  赛博朋克的光被雨幕糊开，神族的光**没有一丝模糊**，边界清楚。虫族则把「向内」推到极端：
  生物朋克还在培养皿里（有边框、有玻璃），虫族连边界都没有。

  九个位置：线（蒸汽）→ 面（柴油）→ **顶灯（人族）** → 反射（原子）→ 向外 bloom（赛博）
  → **锐利（神族）** → 向内（生物）→ **无边界向内（虫族）** → 零位（磁带）→ 太阳（太阳朋克）。

- 千禧美学又加了**两个不在轴上的位置**，理由与其它都不同：**孟菲斯是「无光」而 Webcore 是「假光」**。
  孟菲斯的图案是**印**在板材上的，连明暗梯度都没有（比磁带的「零位」更彻底 —— 磁带还有日光灯的均匀光）；
  Webcore 的老式 3D 边框靠两道 1px 边的明暗对比**假装**立体，与真实光照无关。
  两者都证明这条轴的真正刻度是「光从哪来」，而不是「有没有明暗」。

## 六、关于依据的诚实声明

各规格文档中，凡是 **`doc/punks/` 卷内有明确依据**的内容，都标注了卷内出处；凡是**卷内未涉及、由本项目推断**的内容（**尤其是全部色值**——五卷都只给色相名，无一给出 hex），都显式标注为「外部推断」。

这样做有两个原因：

1. 卷内多处明确要求「文档未涉及的不编造」（生物朋克卷与蒸汽朋克卷尤其强调）；
2. 皮肤的色值是可执行的实现决策，把它伪装成「有出处的考据」会污染整套资料的可靠性。
