# 12 · 千禧美学：五个家族与 Aero 扩支

> 本文是 `千禧美学` 分类下新增家族的规格。依据是 `doc/千禧美学卷/`（十篇调研卷），
> **卷内依据**与**外部推断**在下文分开标注 —— 色值与上一批一样全部是推断，
> 卷子只给视觉清单与物件，不给 hex。
>
> 与三个种族一样：全部是**纯 CSS 的美学演绎** —— 零外部资产（C8）、
> 不出现任何商标、徽章与厂商标识、不向界面注入文字（C9）。这一条对 Webcore 与
> 中文千禧两支尤其要紧，因为那两支的原始素材里**满是**徽章与招牌文字。

## 一、为什么这五个家族各自成立

卷 01 给的成员谱系树是：

```
Memphis（1980s 中期—1990s 中期，祖先）
   ├── Y2K 美学（约 1998—2003）＝镀铬/半透明/果冻
   │      其后继：Frutiger Aero（约 2004—2013）＝玻璃/水滴/绿叶
   ├── Webcore / 网页 1.0（对象 1995—2003）
   └── McBling（约 2004—2008）＝粉彩亮片（时尚侧旁支）
```

五个家族正好覆盖树上的每一个节点，**加上卷 07 单列的中文地方线**：

| 家族 | 卷内位置 | 一句话 | 与已有家族的分界 |
| --- | --- | --- | --- |
| `MemphisFamily` | 祖先 | 俗艳几何 + 塑料层板 | **唯一不是屏幕美学的一支**：图案是印在板材上的，不是光照出来的 |
| `WebcoreFamily` | 核心成员 3 | 低保真个人主页 | 与所有其它家族的分界是**精度**：它是唯一刻意做"低分辨率"的一支 |
| `Y2KFamily` | 核心成员 1 | 镀铬与半透明果冻 | 与 Aero 的分界（卷 01 已辨析）：Y2K 是**锐利金属**，Aero 是**圆润清透** |
| `FrutigerAeroFamily` | 核心成员 2 | 玻璃水滴绿叶 | 已有，本次扩到 7 支 |
| `McBlingFamily` | 旁支 | 粉彩、亮片、缎面 | 与 Y2K 的分界：亮片是**颗粒反光**，果冻是**体透光** |
| `ChineseY2KFamily` | 卷 07 | 网吧、QQ 空间、4399 | 卷 06 批评篇第 3 条批评「用美式词条框定全球千禧，遮蔽地方经验」—— 这一支就是那条批评的正面回应 |

卷 07 那句话是本分类里最该听的一句：**「中文语境里，『千禧互联网』首先是一串物件与场所，其次才是视觉风格」**。
所以 `ChineseY2KFamily` 不做 mood board，做**场景**。

## 三、材质与形式语言

判据同 `01_设计方法.md` 第六节：缩成 64×64、去掉颜色，仍能认出是谁。

| 家族 | 材质签名（去色后仍成立） |
| --- | --- |
| Memphis | **1px 黑描边 + 大块几何图案印在层板上**（图案是印刷，不是光影） |
| Webcore | **刻意低精度：1px 双色立体边框 + 抖动图案**（唯一一支「分辨率不够」是设计意图） |
| Y2K | **硬边镀铬高光带 + 果冻的内透光**（有棱角的透明，与 Aero 的无棱角透明相对） |
| McBling | **高密度亮片颗粒 + 缎面渐变**（blinn 是颗粒反光，不是玻璃透光） |
| 中文千禧 | **CRT 扫描线 + 冷白光管的光晕**（网吧：日光灯是唯一光源，屏幕是唯一暖色） |

**光的方向轴**再加两个位置：Memphis 是**无光**（印刷图案不吃光，与磁带的"零位"接近但更彻底：
磁带还有日光灯的均匀光，Memphis 连明暗梯度都没有）；Webcore 是**边框自发光**
（老式 3D 边框靠两道 1px 边的明暗对比"假装"立体，与真实光照无关）。

## 四、FrutigerAero 扩支（3 → 7）

卷 05 的媒介考古给了四个具体物件，一支一个：

| 新增 | 依据（卷 05） | 取向 |
| --- | --- | --- |
| `BlissMeadow` | Windows XP 默认壁纸 Bliss（草原蓝天） | 最"默认"的一支：一代人的默认未来 |
| `VistaAurora` | Vista/7 的 Aero 玻璃 + Aurora 壁纸 | 最"夜"的一支 |

## 五、分类、顺序与改名

- `千禧年美学` → **`千禧美学`**（更简洁，也贴近卷 07 的中文用法）；
- 家族新增 `order` 字段：同一分类内的排序键。目录册按「分类 → order → id」排，
  面板直接按目录册顺序渲染 —— **顺序是数据，不是显示逻辑**。
- 本分类的行内顺序按血缘与年代：孟菲斯(110) → 网页1.0(120) → Y2K(130) → Aero(140)
  → McBling(150) → 中文千禧(160)。中文千禧排在最后：它是**地方线**，与美式词条并列而不混入。
- 顺带把朋克类的行内顺序改成**光谱轴序**（生物 → 赛博 → 原子 → 柴油 → 蒸汽 → 磁带 → 太阳）——
  `docs/README.md` 第四节早就写着「面板里的家族顺序应当按它排列」，但一直按家族 id 字母序排，
  这次一并修掉。

## 六、雷区（据卷 06 批评篇）

1. **不复制徽章与招牌。** Webcore 与中文千禧的原始素材里满是「最佳浏览 800×600」「施工中」
   这类徽章与文字招牌。C9 已经禁止注入文字，这里再明确一次：**连图形化的徽章也不做** ——
   那会把这些皮肤变成贴纸簿。
2. **不把"低分辨率"做成嘲弄。** 卷 06 第 2 条批评「去语境化：词条把年代的苦难面抹成 mood board」。
   Webcore 的窄带痛苦（拨号、加载五分钟）是那一代经验的一部分；皮肤可以低精度，
   但不可以**滑稽**。区分标准：低精度是为了还原一种限制，不是为了让人笑。
3. **中文地方线要正面呈现。** 卷 06 第 3 条批评「谁有资格怀旧」；卷 07 把网吧与 QQ 空间
   作为**第一现场**而非怀旧消费品。所以 `ChineseY2KFamily` 不做土味调侃、
   不用"杀马特"式的视觉猎奇，按场景考古做。
4. **怀旧商品化这条在皮肤里天然成立**（皮肤就是"出售符号使用权"）。卷 06 给的判别标准是
   「它是否参与生产新的未来想象」—— 本分类的做法是：**把结构与机制做成可调参数**
   （`chrome` 的硬边、`badge` 的边框感、`scanline` 的扫描线），让用户自己决定要多"复古"，
   而不是给一张固定死的气氛图。
