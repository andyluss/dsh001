# 04 · 原子朋克（Atompunk）

> 对应卷：`doc/punks/atompunk/`
> 家族 id：`AtompunkFamily` · 建议 variant 数：4

---

## 一、分支速览

**一句话**：回望标签 + 风格标签 + 世界观设定**三合一**。回望目标约 **1945—1969** 的前数字时代美国。

**核心张力：双面未来**

> **幸福原子与核末日同源共档**——同一套物理、同一个机构（美国原子能委员会）、同一家印刷厂、同一批商业插画语汇。氛围词卷内定为「**乐观、可怖**」。

这不是「亮面与暗面两个主题」，而是**同一张底片的两面**。所以本家族的第五个公共设计手段是 `flipside`（双面底片开关）——**任何一支 variant 都能一键翻到另一面**，因为它们本来就共用同一套骨架与同一个放射红橙。

**命名节点**：2008 年 12 月斯特林与多克托罗**同日发文**。回收史：1981 吉布森《Gernsback 连续统》→ 1982 纪录片《原子咖啡厅》→ 1997《辐射》→ 2010 年代词条化。

**时代底座**：末端约 1969（登月 + 微电子）。能源＝**核能 × 按钮**。材料＝**塑料、镀铬、瓷釉**。界面＝**按钮与旋钮，前数字时代**。

> ⚠️ **卷内明确排除**：CRT 与磁带属于**磁带未来主义**，不是原子朋克的界面底座——它们只在《辐射》式的**第三序混血**里被焊接进来。**本家族的皮肤不得出现 CRT 扫描线、绿字终端、磁带暖噪声。**

**档案器物（务必保留）**：末日时钟 1947、莱维敦 1947 起、雷神「雷达炉」微波炉 1947 前后、吉尔伯特 U-238 原子能实验室 1950—51、鹦鹉螺号与奥布宁斯克 1954、孟山都未来之家 1957、原子球与 1958 布鲁塞尔世博会、迪士尼明日世界 1955 起、Googie 咖啡屋约 1949。

## 二、配色规格

**卷内只给色名，无任何 hex／Pantone**。以下落地取值为**外部推断**。

| 语义 | 取值 | 用途 |
| --- | --- | --- |
| 奶油白 | `#F3EBDD` | 页面底（主） |
| 薄荷绿 | `#A8CDBB` | 底（副）、次级面板 |
| 瓷釉白 | `#FBF7F0` | 输入区、卡片 |
| 镀铬 | `#D8DDE2` → `#9AA3AA` | 镜面高光渐变 |
| 放射红橙 | `#E4572E` / `#F26B21` | **唯一的高饱和色**：主行动、危险、焦点 |
| 民防黄 | `#E8B923` | flipside 侧的警示 |
| 民防黑 | `#1A1A1A` | flipside 侧的底 |
| 正文 | `#2B2622` | 主文字 |
| 次要文字 | `#6B6259` | 说明、标签 |

**关键决策**：**红橙是唯一的高饱和色**。奶油白与薄荷绿是底，镀铬是材质，**只有红橙出现在需要「行动」或「危险」的地方**——这正是「放射色」的双义性：它同时意味着能量与威胁。

## 三、材质与形式语言

- **镀铬**：**镜面高光**——用多层 `linear-gradient`（一条亮带、一条暗带、再一条亮带）模拟金属反射，**硬边、高对比、可预测的反光角度**。
- **瓷釉与塑料**：**完全不做旧**。没有颗粒、没有划痕、没有噪点——这是它与柴油朋克、蒸汽朋克最硬的分界。1950 年代的未来是**新的**。
- **形态**：垂直尾鳍（1948 年起哈利·厄尔受 P-38 启发移植到凯迪拉克）、流线、Googie 的斜挑悬垂屋顶与尖角招牌。圆角**大而有方向感**（不是等圆角）。
- **原子图案系统**（卷内 signature，本家族的核心图形语言）：

| 图案 | 用途 |
| --- | --- |
| 轨道环（椭圆环绕核心） | 环形进度、加载态 |
| 星爆纹（四角星） | 焦点标记、徽标底 |
| 放射线条 | 分隔线、标题两端收束 |
| 太阳形 | 空状态 |

- **交互必须是旋钮与按钮**：滑杆做成**旋钮式**（圆形拨档、带行程按压反馈）。这是这一支的身份，也是它与其它六支最容易分辨的地方。
- **字体**：卷内只给了一句可执行描述——「暖色调、圆角排版、微笑的人物与卡通化的威胁」。**具体字体未涉及**。落地选择：圆润的几何无衬线，字重偏中，不做高对比衬线。

## 四、家族参数

公共参数：`glass` / `blur` / `accent` / `intensity` / `motion`。

| key | type | 范围 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `radiation` | number | 0–100 | 62 | 放射色：红橙的饱和度与出现频率 |
| `chrome` | number | 0–100 | 70 | 镀铬：镜面渐变的对比度与覆盖面 |
| `flipside` | boolean | — | false | **双面底片**：翻到民防／末日那一面 |

> `flipside` 是本家族的招牌机制。它不换 variant，只把**同一套骨架**推到另一面：底色转为民防黑与黄、加末日时钟刻度、放射色从「能量」语义转为「威胁」语义。

## 五、Variant 清单

### V1 · `ChromeSuburb` 镀铬郊区（幸福原子，标准支）

- **场景**：卷内子风格①②⑤⑥的综合——镀铬郊区、Populuxe 消费繁荣、Googie 建筑。莱维敦、孟山都未来之家、Googie 咖啡屋。
- **壁纸**：奶油白底 + 右上薄荷绿的柔和渐变 + 底边一条镀铬横向亮带（多层 `linear-gradient`）+ 极淡的放射线从底部升起。
- **材质**：瓷釉的干净平面、镀铬的硬边高光、尾鳍式的大圆角。
- **动效**：**镀铬扫光**——底边的镀铬亮带以 14s 周期做一次横向扫过（`transform: translateX`，用 `steps()` 模拟反射，不做平滑渐变）。
- **defaults**：`{"glass": 58, "radiation": 55, "chrome": 72, "accent": "#E4572E"}`

### V2 · `DuckAndCover` 民防（末日侧 / 全家族最浓）

- **场景**：卷内子风格②——民防末日侧。卧倒掩护、末日时钟、防空洞。**情绪是「乐观」的反面，但用的是同一套印刷语汇。**
- **壁纸**：民防黑底 + 顶部一片黄黑斜条纹带（`repeating-linear-gradient` 45°，间距宽松，不做密集警戒线）+ 一圈极淡的末日时钟刻度环（位于画面中心偏上）。
- **材质**：**同一套骨架**（大圆角、镀铬描边），但镀铬转为哑光黄铜色；放射红橙在此变为**威胁语义**——用于告警、倒计时、边界。
- **动效**：**时钟刻度**——末日时钟的分针以 60s 周期缓慢推进一格（`transform: rotate`，`steps(60)`）。
- **defaults**：`{"glass": 34, "radiation": 88, "chrome": 40, "accent": "#E8B923"}`

> 视觉上**不出现蘑菇云**。见第七节的雷区处理。

### V3 · `SpaceAge` 太空纪（③④ 太空接头）

- **场景**：卷内子风格③④——第三序混血与太空纪接头。明日世界、原子球、鹦鹉螺号。**更亮、更白、更空**。
- **壁纸**：瓷釉白底 + 一片从下方升起的深蓝渐隐（模拟夜空）+ 稀疏的白色点阵（星）+ 一组同心轨道环（细椭圆环，从中心偏左展开）。
- **材质**：**最干净的一支**——几乎没有材质，只有色块与线；镀铬只做细描边；原子图案系统在这里最完整地被使用（轨道环做进度、星爆做焦点、太阳形做空状态）。
- **动效**：**轨道环旋转**——中心的一组轨道环以 80s 周期缓慢旋转（`transform: rotate`）。
- **defaults**：`{"glass": 66, "radiation": 42, "chrome": 58, "accent": "#2E7DB8"}`

### V4 · `RedAtom` 红旗原子（⑧ 苏联侧）

- **场景**：卷内子风格⑧——红旗原子／苏联侧。奥布宁斯克核电站 1954、1958 布鲁塞尔世博会苏联馆。
- **设计立场**：卷内明确「**勿混美式与苏联美学**」。这一支是**独立的一支**，不是给美式配色换个红——它的形态语言也不同：更**重**、更**少消费感**、纪念碑式的对称与垂直，而不是 Googie 的斜挑与飞翘。
- **壁纸**：冷灰白底 + 一条严格的垂直对称轴线 + 两侧的复沓几何块 + 顶部一片暗红渐变（不发光，是印上去的红）。
- **材质**：**哑光**——不做镜面镀铬（那是消费繁荣的语汇），改用拉丝金属的**低对比横向纹理**；圆角收小；尾鳍变成**垂直的塔尖**而非飞翘的翅。
- **动效**：**垂直脉冲**——中轴线上的一条细亮线以 6s 周期做小幅明度起伏。
- **defaults**：`{"glass": 44, "radiation": 68, "chrome": 30, "accent": "#B3352C"}`

## 七、雷区与规避

卷内点出的雷区，逐条给本项目的做法。

| 雷区 | 卷内依据 | 本项目的规避 |
| --- | --- | --- |
| **蘑菇云不可当纯装饰** | 卷内判据：「关键不在图案，而在**看点与语境**」 | **本家族的四支 variant 全都不出现蘑菇云**。这是硬约束——在一个长时间注视的工作界面里，蘑菇云无法承载「看点与语境」，只会退化成图案 |
| **受害者缺位** | 广岛长崎、1946 比基尼环礁「十字路口行动」与马绍尔群岛、内华达下风向居民、铀矿工人——这些在「幸福原子」的图像档案里全部消失 | 本项目**不试图用视觉复原这些**（那是展板的工作，不是界面的工作）。取而代之：在**家族与 variant 的描述文本**里写明这段历史坐标，并**不使用**任何把核爆审美化的元素（无云、无闪光、无冲击波环） |
| **「能量等于国运」的语法** | 卷内要求保留「一个引号的距离」 | `radiation` 参数**同时驱动「能量」与「威胁」两种语义**——同一根滑杆，拉高时放射色既更亮也更危险。这个双义性是设计意图，不是含糊 |
| **黑色幽默的两义性** | 笑体制＝清算；笑受害＝消费 | 不做任何戏仿式、玩梗式的视觉元素。民防侧的视觉是**冷峻的**，不是滑稽的 |
| **冷战性别脚本** | 卷内要求勿复制 | 皮肤不涉及人物，天然规避；但**不使用**「家庭主妇 / 防空洞主妇」式的视觉隐喻 |
| **混美式与苏联美学** | 卷内明确要求勿混 | V4 `RedAtom` 是**独立形态**（垂直、哑光、纪念碑式），不是给 V1 换色彩 |

## 八、材质签名（不可互换的那一件事）

> 把界面缩成 64×64 去掉颜色，仍能认出是原子朋克：

**干净的瓷釉平面上，一道硬边的镀铬反光带。**

这是整个七支家族里**唯一一支完全不做旧**的皮肤——没有颗粒、没有划痕、没有雾。其余六支都在某种「材料的老化」上建立识别（黄铜的包浆、胶片的颗粒、霓虹的水汽、组织的湿润、塑料的哑光、木材的手工），**只有原子朋克的未来是新的**。

这个「新」与它另一面的「末日」共用同一张底片——**它的可怖恰恰来自它的干净**。
