# 08 · 太阳朋克（Solarpunk）

> **依据声明**：`doc/punks/` 五卷**未收录**本分支。
> 本规格的**全部内容**来自外部资料与本项目的设计决策，**不声称有任何卷内依据**。
> 与其它七份规格不同，这一份没有「卷内 vs 外部推断」的区分——**通篇都是推断**。

> 家族 id：`SolarpunkFamily` · 建议 variant 数：4

---

## 一、分支速览

**一句话**：近未来，可再生技术 + 社区尺度 + 生态修复。**同样的问题，相反的答案。**

**为什么它必须在这套收藏里占一格**：

其余六支（蒸汽 / 柴油 / 原子 / 赛博 / 生物 / 磁带）设想的未来**全部可疑**——各自主张的伤口分别是阶级、威权、双面核能、不平等、身体商品化、怀旧。整个收藏缺一个**可向往的未来**。缺了它，情绪是单色的。

赛博朋克与太阳朋克是同一枚硬币：同样面对近未来，**一个问「如何活下去」，一个问「如何活得好」**。这一对照本身就是这套皮肤收藏的骨架（见 `README.md` 的光谱图）。

**核心张力（避免做成空洞的绿色乌托邦）**：太阳朋克的张力**不在技术，而在分配**——

- 丰裕之后，**丰裕如何分配**？
- 技术是**集中**的（少数人掌握能源与种子）还是**分散**的（社区自持）？
- 生态修复的代价由谁承担？

一支不做这层张力的太阳朋克，就是「绿色版清新极简」。**这是本规格最主要的对手。**

## 二、配色规格

**全部为设计决策。**

| 语义 | 取值 | 用途 |
| --- | --- | --- |
| 暖白 | `#F7F4EC` | 页面底（主） |
| 晨蓝 | `#DCE9F0` | 底（副）、次级面 |
| 橄榄绿 | `#6B7F4A` | 主色：描边、次级强调 |
| 深叶绿 | `#3D5A34` | 正文层、深色面 |
| 赤陶 | `#C1663B` | 强调：行动、聚焦 |
| 赭石/金 | `#C9A227` | 高光、日照 |
| 玻璃青 | `#A8CFC4` | 玻璃与水的折射 |
| 正文 | `#26301F` | 主文字 |
| 次要文字 | `#5E6B52` | 说明、标签 |

**关键决策**：**赤陶是强调色，绿色是底色**。把绿色当强调色是这一支最常见的失败——整屏绿色会立刻退化成「环保主题网站」。正确的做法是：**绿色构成环境，赤陶承担行动**（陶土是手工与社区的颜色）。

## 三、材质与形式语言

- **手工的不规则**：这是这一支最不可互换的材质。落地手段——**非整数圆角**（如 `13px 11px 14px 12px`，每个角不同）、边缘的极轻微不规则（用 `border-radius` 的非对称组合而非 `clip-path` 的锯齿）。
- **编织纹理**：用两层交叉的极细斜线（`repeating-linear-gradient` 的 ±45°）在低透明度下模拟藤编或织物。
- **日照方向的暖渐变**：光源是**太阳**，有明确方向（左上→右下），且是**暖的、渐变的**，与磁带未来主义的均匀日光灯相反。
- **植物曲线**：新艺术运动（Art Nouveau）式的植物纹样——但**只用于分隔线与边框收束**，不做满屏纹样。
- **玻璃与绿植共生**：玻璃用半透明 + 青色折射（与生物朋克的「膜」不同：这里是**硬的、有框架的**玻璃，不是有机的膜）。
- **字体**：正文用系统默认（可读优先）；标题可用带轻微人文感的衬线。**不做花体**。

## 四、家族参数

公共参数：`glass` / `blur` / `accent` / `intensity` / `motion`。

| key | type | 范围 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `canopy` | number | 0–100 | 50 | 绿植覆盖：植物纹样与绿意的密度 |
| `sun` | number | 0–100 | 62 | 日照强度：暖渐变的强度与方向感 |
| `craft` | number | 0–100 | 58 | 手工质感：不规则边缘与编织纹理的明显程度 |

> `craft` 是这一支的身份证。**把它拉到 0，这一支就会退化成普通的小清新绿色主题**——这正是本规格要对抗的那件事，所以它必须是一个可调的、显式的维度。

## 五、Variant 清单

### V1 · `Glasshouse` 温室（标准支）

- **场景**：玻璃与绿植共生。社区尺度的温室、共享的种植空间。
- **壁纸**：暖白底 + 右上大片暖黄日照渐变 + 底部一排极淡的植物剪影（用重复的弧形 `radial-gradient` 模拟叶片的轮廓，透明度 0.06）+ 一条玻璃格栅（细网格）。
- **材质**：有框架的玻璃（1px 描边 + 内嵌亮边）、非整数圆角、轻微编织纹。
- **动效**：**日照位移**——暖黄渐变以 120s 周期极缓慢地横向位移（`transform: translateX`，幅度 2%），模拟日照推移。
- **defaults**：`{"glass": 60, "canopy": 50, "sun": 62, "craft": 58, "accent": "#C1663B"}`

### V2 · `Terracotta` 陶土（手工与社区侧）

- **场景**：去掉玻璃，只留手工。陶土、赭石、木构——社区自建的那一面。
- **壁纸**：赤陶偏暖的底 + 明显的编织纹理（±45° 交叉细线，透明度 0.05）+ 底部一片赭石色的暖渐变。
- **材质**：**最粗糙的一支**——边缘的不规则最明显、圆角最不整齐、纹理最可见；玻璃元素极少（只有输入区）。
- **动效**：**窑火微光**——底部赭石渐变以 10s 周期做极小幅度的明暗起伏。
- **defaults**：`{"glass": 44, "canopy": 24, "sun": 70, "craft": 88, "accent": "#9E4A28"}`

### V3 · `Overgrown` 蔓生（生态修复侧 / 全家族最浓）

- **场景**：生态修复完成后的样子——建筑被植物覆盖。这是太阳朋克最标志性的画面。
- **壁纸**：深叶绿底 + 大量层叠的植物剪影（三层不同尺度的弧形点阵，透明度 0.05/0.08/0.10，形成纵深）+ 从左上透下的一束暖光（斜向 45° 的宽 `linear-gradient`）。
- **材质**：**绿意最重**——环境色整体偏绿，面板的边缘被植物纹样咬合（边缘的圆角处叠一小簇叶片形状）。
- **动效**：**叶片摇曳**——最外层的叶片剪影以 16s 周期做极小幅度的旋转与位移（`transform: rotate(0.6deg) translateY(2px)`），模拟微风。
- **defaults**：`{"glass": 38, "canopy": 92, "sun": 48, "craft": 62, "accent": "#C9A227"}`

### V4 · `Dawnlight` 晨光（克制侧）

- **场景**：太阳朋克里最冷静的一支——清晨的工作台，绿意在窗外而不在屏幕上。
- **壁纸**：晨蓝底 + 一条地平线式的暖白带（从底部升起）+ **极少**的绿（只有底边一条细绿线）。
- **材质**：**最规整的一支**——圆角整齐、纹理最少、`craft` 最低；玻璃与线条为主。
- **动效**：**晨光渐亮**——地平线暖白带以 180s 周期极缓慢地变亮再变暗（一个近乎不可察觉的循环，只动 `opacity`）。
- **defaults**：`{"glass": 72, "canopy": 10, "sun": 40, "craft": 22, "accent": "#2E7DB8"}`

## 七、雷区与规避

**注意**：以下雷区**没有卷内依据**（该卷不存在），全部来自外部资料与本项目的判断。

| 雷区 | 本项目的规避 |
| --- | --- |
| **退化成「绿色版清新极简」** | 这是最主要的对手。`craft`（手工质感）参数就是为此存在，且默认值压在 58 而非 0；`Terracotta` variant 专门承担手工维度 |
| **退化成「环保主题网站」** | **不把绿色用作强调色**。绿色是环境，赤陶是行动 |
| **空洞的乌托邦** | 家族描述里写明它的核心张力是**分配**而非技术（见第一节）。不做「科技解决了所有问题」式的视觉修辞——不出现无穷符号、不出现「100% 清洁」式的标语式图形 |
| **新艺术运动纹样滥用** | 卷内其它分支的教训（拜占庭式装饰会吞掉可读性）：植物纹样**只用于分隔线与边框收束**，不做满屏纹样，不进入内容区 |
| **与生物朋克混淆** | 两家都涉及「有机」，但材质签名互斥：生物朋克是**湿润的、向内发光的膜**（碳的湿件），太阳朋克是**干燥的、有框架的玻璃与纤维**（手工的建造）。前者没有硬边，后者有明确的框架 |

## 八、材质签名（不可互换的那一件事）

> 把界面缩成 64×64 去掉颜色，仍能认出是太阳朋克：

**每个角都不一样的不规则圆角，配一层编织纹理。**

七个（未来的八个）家族里，只有太阳朋克的边缘**不是被机器加工出来的**——它像是被手工裁切、编织、拼装的。这是它唯一不可被换色替代的特征，也是它对抗「绿色版清新极简」的唯一武器。

对应的是它的政治内容：**社区尺度的、分散的、可参与的建造**，而不是集中生产的完美表面。
