# 07 · 磁带未来主义（Cassette Futurism）

> 依据来源：`doc/punks/cyberpunk/` 卷内把它作为**对照项**讨论 + **外部资料**（社区已有成熟的主题色板与设计规范）
> 家族 id：`CassetteFuturismFamily` · 建议 variant 数：4

---

## 一、分支速览

**一句话**：80 年代技术想象的另一面——不是霓虹雨夜的街头，而是**机房日光灯下的工作台**。

**卷内依据（关键）**：赛博朋克卷把它作为对照项，并给出了最锋利的判别——

> 「共享同一批 80 年代界面，但改机房日光灯的均匀白光、米白塑料＋荧光绿字，气质是**可修、可懂的暖**——加几缕霓虹与义体即滑回赛博，**边界本质是布光与气氛的边界**。」

**为什么它够格独立成家族**：它和赛博朋克共享技术年代，但**器物完全不同**：

| | 赛博朋克 | 磁带未来主义 |
| --- | --- | --- |
| 光 | 雨夜霓虹、湿面倒影 | **机房日光灯、均匀无影** |
| 材料 | 金属、玻璃、湿塑料 | **米白 ABS 塑料、拉丝铝、灰色机箱** |
| 器物 | 义体、全息广告、飞行车 | **CRT 终端、软驱、磁带、拨号调制解调器** |
| 情绪 | 失控、宿命、腐坏 | **可修、可懂、可托付** |

按 `01_设计方法.md` 的判据（时代物质底座），这是两个 family。

> ⚠️ **与原子朋克的对照**：原子朋克卷**明确排除** CRT 与磁带（那是磁带未来主义的）。所以 **CRT 扫描线是这一支的核心语汇，却是原子朋克的禁区**——两支之间不能互相借。

**外部资料**：社区已有把它做成完整主题色板的先例，其自述「Analog Dream」范式：CRT 显示器、NASA 控制台、复古科技；灵感来自 **Neon Genesis Evangelion 的 UI、Apple II、Commodore 64**；并且**以 WCAG AAA（≥7:1）为目标**。这与本项目的工程约束 C4 同向，是难得的一支「美学与可读性天然一致」的分支。

## 三、材质与形式语言

- **哑光塑料与模具缝**：**无渐变的平坦色块**（这是它与原子朋克镀铬最硬的区别）+ **1px 内嵌亮边**（模拟注塑件的倒角）+ 细窄的模具缝线。
- **方正**：圆角极小（2–4px）。80 年代的控制台是**方的**。
- **日光灯的均匀白光**：与赛博朋克完全相反——**没有方向性光源**，整个界面亮度均匀，没有 bloom、没有暗角。
- **CRT 语汇**：扫描线（细横纹）、荧光单色辉光、字符的轻微色散。**只在终端类元素上使用**（代码块、状态机），不做全屏扫描线。
- **交互必须带机械反馈**：按下有行程（`transform: translateY(1px)` + 内阴影），拨杆与按键而不是平滑的过渡。
- **字体**：等宽是这一支的正文候选（Commodore 64 / Apple II 的语汇），且**外部色板已验证等宽 + 米白底可达 AAA 对比度**。

## 五、Variant 清单

### V1 · `BeigeTerminal` 米白终端（标准支）

- **场景**：Apple II / Commodore 64 的米白机箱 + 绿色单色屏。这一支就是「可修、可懂的暖」本身。
- **壁纸**：米白底 + 极淡的注塑件纹理（极细的斜向 1px 条纹，透明度 0.03）+ 无渐变、无噪点、无暗角。
- **材质**：平坦色块 + 1px 内嵌亮边 + 模具缝线；圆角 3px；日光灯式均匀照明。
- **动效**：**光标闪烁**——仅在等宽元素上做 1.2s 方波闪烁（与赛博朋克 V2 同一个动效语义，但这里用的是米白底与深绿字）。
- **defaults**：`{"glass": 24, "phosphor": 35, "scanline": 30, "warmth": 82, "accent": "#2F7A3E"}`

### V2 · `MagneticNight` 磁夜（暗色档标准）

- **场景**：外部色板的暗色档。深夜机房，只有屏幕亮着。
- **壁纸**：深钢灰底（`#1a1d21`）+ 顶部一片极淡的琥珀色辉光 + 一层非常轻的均匀噪点（模拟磁带噪声的视觉等价物）。
- **材质**：同 V1 的哑光与内嵌亮边，但整体压暗；CRT 辉光在暗底上最明显。
- **动效**：**辉光呼吸**——琥珀辉光以 9s 周期做极小幅度的强度起伏（只动 `opacity`）。
- **defaults**：`{"glass": 34, "phosphor": 72, "scanline": 55, "warmth": 18, "accent": "#ffb86c"}`

### V3 · `ControlRoom` 控制室（NASA 控制台取向）

- **场景**：外部资料自述的「NASA consoles」。成排的灰色面板、指示灯阵列、拨杆。
- **壁纸**：中性灰底 + **一排等距的指示灯点阵**（用 `radial-gradient` 的重复点阵，两种亮度交错）+ 无辉光、无噪点。
- **材质**：**最规整的一支**——严格等距、无圆角（0–2px）、面板之间用凹槽分隔（`inset` 阴影的细线）。**装饰是零**：只有功能性的分隔与指示灯。
- **动效**：**指示灯轮询**——点阵中的高亮点以 3s 周期沿行推进（`transform: translateX` 于一个覆盖用的亮点层，`steps()` 缓动）。
- **defaults**：`{"glass": 18, "phosphor": 28, "scanline": 12, "warmth": 34, "accent": "#8be9fd"}`

### V4 · `TapeDeck` 磁带机（消费电子侧 / 全家族最暖）

- **场景**：80 年代消费电子的正面——拉丝铝面板、橙色 LED 数字显示、机械按键、磁带仓。
- **壁纸**：深棕灰底 + 一条横向的拉丝铝带（`repeating-linear-gradient` 的极细横纹）+ 右下角一片橙色辉光（LED 显示）。
- **材质**：**拉丝金属**（这一支唯一用金属质感的 variant）+ 硬边方角 + 明显的机械按键行程（按下位移 2px）。
- **动效**：**磁带转动**——左上角两个并排的小圆以 4s 周期同步旋转（`transform: rotate`，模拟卷带轮）。
- **defaults**：`{"glass": 30, "phosphor": 62, "scanline": 20, "warmth": 66, "accent": "#FF7A18"}`

## 七、雷区与规避

| 雷区 | 依据 | 本项目的规避 |
| --- | --- | --- |
| **滑回赛博朋克** | 卷内：「加几缕霓虹与义体即滑回赛博」 | **硬禁止**：不使用品红／青的霓虹对撞、不使用 bloom、不使用暗角与方向性光源。全家族只有单色辉光与均匀照明 |
| **怀旧的甜腻** | 外部风险 | 不做「复古滤镜」式的做旧。磁带未来主义的暖来自**材料本身**（米白塑料、拉丝铝），不是来自做旧噪点 |
| **可视性倒退** | 80 年代终端确实是低分辨率的 | 借用它的**网格与等距**，不借用它的**低对比**。外部色板以 AAA 为目标，本项目沿用这条标准 |
| **与原子朋克混淆** | 原子朋克卷明确排除 CRT 与磁带 | 两家的材质签名互斥：原子朋克是**镀铬镜面 + 完全不做旧**，磁带未来主义是**哑光塑料 + 内嵌亮边**。不互相借语汇 |

## 八、材质签名（不可互换的那一件事）

> 把界面缩成 64×64 去掉颜色，仍能认出是磁带未来主义：

**平坦的哑光色块，边缘一道 1px 的内嵌亮边。**

七个家族里，蒸汽朋克的边是**磨出来的**、原子朋克的是**镜面反射**、柴油朋克的是**硬边切割**、赛博朋克的是**向外扩散的光**、生物朋克的是**向内透出的膜**、太阳朋克的是**不规则的**——只有磁带未来主义的边是**注塑件倒角的反光**：一条均匀的、无方向性的细亮线。

它对应的是「一块可以被拆下来、修好、再装回去的塑料」。
