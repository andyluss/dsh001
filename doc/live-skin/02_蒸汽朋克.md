# 02 · 蒸汽朋克（Steampunk）

> 对应卷：`doc/punks/steampunk/`
> 家族 id：`SteampunkFamily` · 建议 variant 数：4

---

## 一、分支速览

**一句话**：把超前技术「翻译」成蒸汽、齿轮与黄铜的语法，基座是维多利亚时代（1837—1901）。

**命名（卷内关键事实）**：1987 年 K. W. 杰特致《Locus》杂志的信中提出「steam-punks」——蒸汽＋借自赛博朋克的「朋克」。**文本早于标签近三十年**（文本史自 1959 年皮克《泰特斯独行》），是典型的「追溯命名」。

**三层张力（决定了皮肤要表达什么）**：

1. **双层时间**——它回望的**不是**维多利亚的真实当下，而是后世反推、**从未被许诺也未存在**的「维多利亚可能拥有的蒸汽未来」。
2. **词缀错位**——「蒸汽」指时代能源与界面，「朋克」多停在装饰层，**反叛衰减为恋物**。
3. **可见之暖对帝国之冷**——承诺技术可被个人修理，却把殖民暴力清洗成布景。

> **对皮肤的直接影响**：第 1 条意味着这是所有分支里**最纯粹的「复古未来」**——它没有对应的真实年代可以忠实，只有一份被反复转译的想象。第 3 条决定了一支 variant 的设计立场（见 V4）。

**时代底座**：能源＝蒸汽与煤。材料＝黄铜、皮革、木材（「有温度的工业」）＋煤烟灰与铅色。器物＝巴贝奇差分机、飞艇、高架铁道、巨型钟楼、煤气灯拱廊车站、仪表刻度盘、自动人偶、机械甲虫。城市＝烟囱林立的纵向都市。

> **注意**：电力（发电机、电话、博览会弧光）是维多利亚许诺的「电的未来」，**恰是本类型不回收的部分**。弧光不属于蒸汽朋克的语汇。

## 三、材质与形式语言

- **黄铜是「带包浆的旧铜」而不是镜面新铜**。高光要**沿边缘**走（`:inset` 的细亮边 + 顶部渐隐），不要平面中央的大块反光。
- **「结构件即装饰」**：齿轮、活塞、连杆不藏进外壳。落地手段——边框用「金属包边」（双层边框 + 四角小圆点模拟铆钉），分隔线用齿边（`repeating-linear-gradient` 的方波）。
- **圆**：齿轮的圆。圆角取中到大（10–16px），与赛博朋克的「切割」形成对照。
- **仪表刻度盘作组件语言**：进度、状态、数值都可以做成表盘＋指针＋刻度＋铜圈的语义。这是这一支最有效的「看得见的界面」。
- **字体**：卷内**未涉及**。落地选择：标题可用高对比衬线（不做花体），正文用系统默认，数据用等宽。
- **光效**：煤气灯的**暖黄低照度局部照明**＋雾中散射。单一光源、暗角、高光落在黄铜边缘。

## 四、家族参数

公共参数：`glass` / `blur` / `accent` / `intensity` / `motion`。

| key | type | 范围 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `patina` | number | 0–100 | 45 | 铜绿：把黄铜从新铜推向氧化的旧铜 |
| `gaslight` | number | 0–100 | 62 | 煤气灯：暖黄光源的强度与范围 |
| `haze` | number | 0–100 | 40 | 雾感：雾中散射的浓度与暗角深度 |

## 五、Variant 清单

### V1 · `Brassworks` 黄铜工坊（装饰—冒险取向，标准支）

- **场景**：卷内的主流取向——复古装饰与冒险，符号可穿戴。煤气灯拱廊车站、外露的齿轮与管道。
- **壁纸**：煤烟灰底 + 右上暖黄径向辉光（煤气灯）+ 底部一层极淡的铜色地平线 + 极淡的雾噪点。
- **材质**：金属包边边框（双层 + 铆钉点）、齿边分隔线、黄铜边缘高光。
- **动效**：**齿轮转动**——一个装饰性的齿轮环以 40s 周期缓慢旋转（`transform: rotate`，放在壁纸层，不遮挡内容）。
- **defaults**：`{"glass": 52, "patina": 45, "gaslight": 62, "haze": 40, "accent": "#B08D57"}`

### V2 · `Gaslight` 煤气灯（煤气灯奇幻取向）

- **场景**：卷内列为相邻术语——偏奇幻、机械与角色浪漫，工程学浓度略低。**唯一光源是煤气灯**。
- **壁纸**：近黑底 + 三处错落的暖黄光斑（煤气灯）+ 明显的雾（径向渐变的低频噪声）。
- **材质**：对比度最高的一支——大面积暗部、只有边缘被照亮；面板几乎实色，只在描边上有一道暖黄。
- **动效**：**灯火摇曳**——三个光斑以不同周期（6.5s / 9s / 12s）做极小幅度的透明度起伏（只动 `opacity`）。
- **defaults**：`{"glass": 34, "patina": 30, "gaslight": 88, "haze": 72, "accent": "#FFC46B"}`

### V3 · `DifferenceEngine` 差分机（思想实验取向）

- **场景**：卷内的思想实验取向——把蒸汽世界当历史哲学的试验台（《差分机》式反事实推演）。**更冷、更精确、更少装饰**。
- **壁纸**：深铁色底 + 极规则的细网格（穿孔卡的孔阵，1px 点阵）+ 顶部一条冷白刻度带。
- **材质**：**去装饰**——不加铆钉与齿边，改用刻度线与编号；圆角收小（6px）；黄铜只出现在数值与刻度上，不用于大面积。
- **动效**：**穿孔卡推进**——一条细横带以 30s 周期自上而下步进（`transform: translateY`，步进用 `steps()` 缓动，模拟机械而非流体）。
- **defaults**：`{"glass": 46, "patina": 12, "gaslight": 30, "haze": 18, "accent": "#C9A227"}`

### V4 · `BoilerDeck` 锅炉舱（修正取向 / 全家族最浓）

- **场景**：卷内点出的**阶级与性别盲点**——「绅士发明家占前台，司炉、工人、仆役退为背景，煤烟、工时、贫民窟、工伤被审美化过滤」。这一支把视角**从客厅移到锅炉舱**。
- **设计立场**：这是对雷区的正面回应，不是又一支装饰性的蒸汽朋克。视觉上**主动放弃体面**：黄铜退为配件，铁灰与煤烟成为主体。
- **壁纸**：铁灰底 + 底部一片暗红炉火的辉光 + 厚重的煤烟噪点（透明度 0.07 的细密噪点）。
- **材质**：**粗糙**——面板有可见的接缝与磨损（用不规则的 `border-radius` 与内阴影模拟磕碰），黄铜只在阀门与压力表上出现。
- **动效**：**压力脉动**——炉火辉光以 4.5s 周期做小幅明暗起伏，模拟燃烧的不稳定（只动 `opacity`）。
- **defaults**：`{"glass": 30, "patina": 78, "gaslight": 40, "haze": 66, "accent": "#C1663B"}`

## 七、雷区与规避

| 雷区 | 卷内依据 | 本项目的规避 |
| --- | --- | --- |
| **帝国复魅与殖民清洁化** | 帝国与殖民网络是默认舞台，地图、茶会、军服、异域战利品反复演出体面；批评说认为这清洗暴力。**两说悬而未决**（有辩护说主张架空挪用不等于政治背书） | **不做异域战利品式的装饰**。不使用殖民地地图、异国纹样的拼贴。不使用军服、勋章、帝国徽记 |
| **阶级与性别盲点** | 绅士发明家占前台，司炉、工人、仆役退为背景；煤烟、工时、贫民窟、工伤被审美化过滤 | V4 `BoilerDeck` **就是这个雷区的设计回答**——把劳动放到前台。家族层面则保证：煤烟与磨损是**可见的**，不是被擦干净的 |
| **装饰还是姿态** | 判别标准是器物为怀旧道具（装饰）还是质询技术、劳动、权力（姿态）；要看机械运转的社会后果，而非「黄铜件数」 | **黄铜密度设上限**。三支 variant 的黄铜只用于边缘与数值，不做整面黄铜 |
| **边界与年代错位** | 1959—1979 的前史作品归属属事后追认且有争议 | 家族描述里如实标注「追溯命名」，不把一个 1987 年的标签安到 1959 年的文本上 |

## 八、材质签名（不可互换的那一件事）

> 把界面缩成 64×64 去掉颜色，仍能认出是蒸汽朋克：

**沿边缘走的黄铜高光 + 结构件外露的齿边。**

赛博朋克的光是**打上去的**（向外 bloom），生物朋克的光是**从材料里透出来的**（向内发光的膜），蒸汽朋克的光是**磨出来的**——它只出现在金属的边缘和转角，平面上什么都不留。这一个区别就足以把三支分开。
