# 06 · 分支外延评估：第六个家族该不该有

> `doc/punks/` 收的是五卷：steampunk / dieselpunk / atompunk / cyberpunk / biopunk。
> 但「××朋克」是一个仍在增殖的命名家族。本文评估哪些外延值得做一个**独立的 LiveSkin 皮肤家族**，哪些更适合作为某个已有家族下的一个 variant。

---

## 一、判据

一个分支值得独立成家族，需要同时满足三条：

| 判据 | 说明 |
| --- | --- |
| **时代的物质底座不同** | 能源 / 材料 / 界面器物与五卷中的任何一卷都不重合。仅仅换配色不算。 |
| **有可复用的视觉母题库** | 能撑起 4~6 个 variant 而不重复自己。做不到就说明它是一支 variant，不是一个 family。 |
| **有依据** | 要么 `doc/punks/` 里有卷内依据，要么外部资料足够系统。 |

第三条是分水岭：**没有依据的部分我不会凭常识编造。**

---

## 二、候选逐个评估

### 1. decopunk（装饰朋克）— 建议：**不独立**，作为 dieselpunk 的 variant

- **依据**：`doc/punks/dieselpunk/` 明确把它列为该卷的子风格之一（「共享战间素材但焦点从动力机器转向装饰的都会，1920—30 年代」）。
- **判断**：它和柴油朋克**共用同一个时代底座与同一批档案**（Art Deco 都会、世博会、摩天楼），差别在焦点（装饰 vs 动力机器）而不在物质底座。作为 `DieselpunkFamily` 下的一支 variant 更准确。
- **落地**：variant `DecoMetropolis` —— 更几何、更对称、更少的军绿与铬银，更多黑金与退台饰条。

### 2. cassette futurism（磁带未来主义）— 建议：**独立成家族**，值得破格

- **依据**：`doc/punks/cyberpunk/` 卷把它作为对照项与子风格明确讨论，并给出了关键判别——「共享同一批 80 年代界面，但改机房日光灯的均匀白光、米白塑料＋荧光绿字，气质是可修、可懂的暖；**与赛博朋克的边界本质是布光与气氛的边界**」。
- **为什么破格**：虽然依据在赛博朋克卷内，但它的物质底座是**另一套器物**——不是霓虹雨夜与义体，而是米白塑料机箱、荧光绿单色终端、磁带与软盘、机房日光灯。母题库足够撑起 4~6 支。
- **外部佐证**：社区已有把它做成完整主题色板的先例，且以 **WCAG AAA（≥7:1）** 为目标——这正好与本项目的工程约束 C4 同向。
  - 深色档「Magnetic Night」：`#1a1d21` 钢灰底 + `#ffb86c` 琥珀辉光 + `#50fa7b` 磷绿
  - 浅色档「Beige Terminal」：`#f5f0e8` 米白底 + `#d65d0e` 复古橙 + `#076678` 深青
  - 灵感自述：Neon Genesis Evangelion 的 UI、Apple II、Commodore 64
- **落地**：`CassetteFuturismFamily`，variant 可含 `BeigeTerminal`（米白+磷绿）、`MagneticNight`（钢灰+琥珀）、`VaporDusk`（暮色紫粉，磁带包装盒配色）。

### 3. solarpunk（太阳朋克）— 建议：**独立成家族**，且是光谱上的必要一格

- **依据**：`doc/punks/` 五卷未收。**外部依据充分**——它是近年最明确成形的一支，且与赛博朋克构成正面对照（同样的近未来，一个问「如何活下去」，一个问「如何活得好」）。
- **为什么值得做**：五卷有一个共同点——**它们设想的未来全部可疑**（蒸汽朋克的阶级、柴油朋克的威权、原子朋克的双面、赛博朋克的不平等、生物朋克的身体商品化）。整个光谱缺一个**可向往的未来**。solarpunk 正是那一格，缺了它，这套皮肤收藏在情绪上是单色的。
- **视觉母题库**：新艺术运动（Art Nouveau）的植物曲线、装饰性框架；竹/木/藤的有机材料；玻璃与绿植共生；陶土与赭石；社区尺度的太阳能与风;暖白、橄榄绿、赤陶、金。
- **风险**：容易做成「绿色版的清新极简」，丢掉它的社区与手工维度。需要在 variant 上把「手工感」（编织纹理、不规则边缘、日照渐变）做出来。
- **落地**：`SolarpunkFamily`，variant 可含 `Glasshouse`（温室：绿+玻璃）、`Terracotta`（陶土+暖白）、`Overgrown`（绿植覆盖建筑）。

### 4. silkpunk（丝绸朋克）— 建议：**暂不做**

- **依据**：外部有明确出处（刘宇昆提出的概念），指向以东亚有机材料与工艺为底的技术想象（竹、丝、纸、木构、风筝与帆）。
- **为什么暂缓**：它需要一套**独立且扎实的东方工艺考据**（形制、纹样、材料的真实谱系）。在缺少这层依据的情况下做，最容易的失败模式就是把它做成「异域纹样贴纸」——而这恰恰是赛博朋克卷已经点名的雷区（把整个语系降格为异域质感）。**宁缺勿滥。**
- **替代**：如果之后要做，应作为独立课题立项，先做资料卷再做皮肤。

### 5. clockpunk（钟表朋克）— 建议：**不做**，并入 steampunk 作 variant

- 它是蒸汽朋克的子集（同一能源与材料底座，更早、更机械、更精密）。作为 `SteampunkFamily` 的 variant `Clockwork` 即可。

### 6. oceanpunk / mythpunk / nowpunk 等 — **依据不足，不做**

这些标签在社区里流通，但缺乏系统化的视觉母题库，且「时代物质底座」与已有卷重叠。凭常识拼凑会直接违反本项目的第三条判据。

## 三、建议的家族清单

| 优先级 | 家族 | id | 依据来源 | 预计 variant 数 |
| --- | --- | --- | --- | --- |
| P0 | 蒸汽朋克 | `SteampunkFamily` | doc/punks/steampunk | 4~5 |
| P0 | 柴油朋克 | `DieselpunkFamily` | doc/punks/dieselpunk | 4~5 |
| P0 | 原子朋克 | `AtompunkFamily` | doc/punks/atompunk | 4~5 |
| P0 | 赛博朋克 | `CyberpunkFamily` | doc/punks/cyberpunk | 4~5 |
| P0 | 生物朋克 | `BiopunkFamily` | doc/punks/biopunk | 4~5 |
| P1 | 磁带未来主义 | `CassetteFuturismFamily` | cyberpunk 卷 + 外部 | 3~4 |

> P0 = 五卷对应，本轮范围；P1 = 建议纳入但可后置；决策见 `00_关键决策.md`。

## 四、光谱视角

把七支放在一条轴上，可以看出这套收藏的完整性：

```
可疑的未来 ←──────────────────────────────────→ 可向往的未来

生物朋克   赛博朋克   原子朋克   柴油朋克   蒸汽朋克   磁带未来主义   太阳朋克
身体商品化  不平等    双面核能   威权档案   阶级回望    怀旧机房      社区共生
（湿件）    （信息）   （原子）   （内燃）   （蒸汽）    （微电子）    （可再生）

时代底座：  近未来 ←──────────────────────────→ 19 世纪
            1945─1969 为原子朋克，1918─1945 为柴油朋克
```

这条轴本身可以成为一个产品层面的事实：**用户在 LiveSkin 的家族列表里看到的不是七个皮肤，而是一条关于「我们曾经如何想象未来」的时间轴。** 建议在 README 与面板里都按这个顺序排列。
