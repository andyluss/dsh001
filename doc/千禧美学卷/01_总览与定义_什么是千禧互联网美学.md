# 千禧互联网美学 · 总览与定义

> 关键词：千禧互联网美学；Y2K 美学；Frutiger Aero；Webcore；McBling；术语族
>
> 摘要：本篇界定"千禧互联网美学"这个伞形概念：它不是单一风格，而是约 1995—2010 年间"数字生活乐观主义"视觉系谱的总称——核心成员为 Y2K 美学、Frutiger Aero、Webcore（网页 1.0 美学），外围含 McBling 与拟物界面哲学；这些标签几乎全部是 2010 年代末以降的词条化命名。本篇给出成员谱系树、命名年代对照与辨析口径，作为全卷地图。

---

## 一、伞形概念与边界

**千禧互联网美学（Millennial / Y2K-era Internet Aesthetics）**是本卷自用的伞形概念，指以"数字生活即将全面到来"为底色的、约 1995—2010 年间产生并集体过时的视觉文化系谱。三点边界说明：

1. **它不等于"2000 年代的全部时尚"**：本卷聚焦与**互联网/个人计算/数字消费**相关的美学（界面、网页、数码产品、数字生活方式），时尚（如低腰裤、亮片）只在作为同一时代情绪证据时旁及；
2. **它既是"当年的现在"，也是"今天的遗产"**：当年这些风格并不自称为"Y2K 美学"——它们就叫"现在"；今天我们看到的是被词条化后的回望版本（主卷 18 千禧篇的核心论点，本卷展开）；
3. **它与复古未来主义的关系**：见卷首 00 对读篇——它是"半衰期最短的复古未来"。

## 二、成员谱系树

按时间与血缘排布（详见 03 美学家族详解篇）：

```
Memphis Design（1980s 中期—1990s 中期，祖先）
        │
        ├──→ Y2K 美学（约 1998—2003）＝镀铬/半透明/果冻/充气家具
        │        其后继：Frutiger Aero（约 2004—2013）＝玻璃/水滴/绿叶/拟物
        │                  （N 世代把两者合称"千禧数字美学"）
        │
        ├──→ Webcore / 网页 1.0 美学（约 1995—2003 的对象；2010s 起命名）
        │         ＝个人主页/跑马灯/计数器/星空背景/施工中 GIF
        │
        └──→ McBling（约 2004—2008）＝bling-bling/粉彩亮片（时尚侧的旁支）
                 （常被并入广义 "Y2K" 讨论；界定分歧见下）
```

另有两条重要的**相邻而不属**的线：
- **蒸汽波（vaporwave，2010s）**：千禧美学遗产的"消费者"——它采样 80—90 年代商场与电脑素材，见主卷 17；
- **拟物设计（skeuomorphism，约 2007—2013 苹果生态）**：是 Frutiger Aero 的界面哲学底座，作为"哲学/技术"维度并入 03 篇论述而非独立家族。

## 四、术语辨析：容易混的四组概念

1. **Y2K 美学 vs 千年虫（Y2K bug）**：千年虫是 1999—2000 年的真实技术恐慌（日期回绕 bug）；Y2K 美学是以"2000 年"为符号的视觉风格。命名同源（都是 "Year 2000"），指向不同。中文偶尔把 Y2K 美学写作"千年虫美学"，不准确，本卷不用。
2. **Y2K 美学 vs Cybercore**：维基百科指出，2020 年代 Y2K 一词泛化后，原义（镀铬式复古未来主义）偶以 Cybercore 称呼——即"窄义 Y2K"与"广义 Y2K（含 2000s 时尚）"之争。
3. **Frutiger Aero vs Y2K 美学**：常被混为一谈。粗分：Y2K 是"即将到来的 2000 年"的锐利金属与半透明；Frutiger Aero 是"已经到来的数字生活"的圆润清透（玻璃、水滴、拟物）。主卷 18 已辨析，本卷 03 篇再给对照表。
4. **Webcore vs "复古网页"复兴**：Webcore 指对 1995—2003 个人网页美学的词条化与再创作（Neocities 运动是其当代实践）；它与"网页考古"（archive 视角）不同——前者造新网页，后者存旧网页，本卷两者都收。

## 五、译名说明（详见 07 中文语境篇）

- Y2K 美学：中文普遍**保留英文 "Y2K"**（小红书/知乎/B 站标签），少用"千年虫美学"；
- Frutiger Aero：中文直接使用英文原名或"玻璃拟物美学"等描述性说法，无统一译名；
- Webcore/网页 1.0：中文常用"网页 1.0 美学/复古网页"；
- 伞形词"千禧互联网美学"为本卷工作词，非通行术语。
