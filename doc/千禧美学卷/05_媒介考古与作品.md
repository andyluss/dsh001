# 千禧互联网美学 · 媒介考古与作品

> 关键词：媒介考古；操作系统；个人主页；Flash；千禧流行文化；档案项目
>
> 摘要：本篇以"考古现场"的方式分媒介盘点千禧互联网美学的物质遗存：操作系统与硬件、网页与软件、Flash 一代、影视音乐与游戏、档案与抢救项目。中文侧细节（QQ 空间、网吧、4399 等）详见 07 中文语境篇，本篇仅作衔接。

---

## 一、操作系统与硬件（"界面的遗骨"）

- **Mac OS X Aqua（2000 公测 / 2001 正式）**：玻璃滚动条、水漾 Dock——Frutiger Aero 的源头界面；
- **Windows XP（2001-10）**：默认壁纸 Bliss（草原蓝天，摄影者 Charles O'Rear，约 1996 年拍摄）与"水银"质感——一代人的"默认桌面"；
- **Windows Vista（2007）/ Windows 7（2009）**：Aero 半透明玻璃窗框与 Aurora 壁纸——Frutiger Aero 的软件总装；
- **iMac G3（1998）**与 iBook 果冻色系：Y2K 半透明塑料（blobject）的家用图腾；
- **初代 iPhone（2007）**：拟物图标（日历、便签、罗盘）——拟物哲学的巅峰物；
- **游戏机与数码**：PS2（2000）、Wii（2006）客厅界面、2000 年代数码相机普及（维基百科 Y2K 词条特地点名"数码相机成为主流"）、诺基亚/索尼爱立信彩屏机（约 2001—2005）与 MP3 播放器。

## 二、网页与软件（"数字街区"的遗存）

- **GeoCities**（1994/1995—2009）：个人主页时代的地层——星空/火焰背景、跑马灯、计数器、留言板、"under construction"GIF、"最佳浏览 800×600"徽章；其"街区（Neighborhoods）"分类（Area51＝科幻等）是 Web 1.0 的民俗学样本（Archive Team 档案）；
- **中文侧**：网易个人空间/ChinaRen 校友录（1999 前后）与 QQ 空间（2005）构成中文"个人主页第二春"（详见 07）；
- **软件生态**：2000s 常见"全 Flash 官网"与 JS 特效站；工具类软件（Winamp 皮肤、屏幕保护程序）是低风险的美学实验场——皮肤文化（换肤）值得单列：它是普通用户最早的"界面 DIY"。

## 三、Flash 一代（约 1996—2020）

- 起源：FutureSplash（1996）→ Macromedia Flash；2000s 成为网页动画与游戏的默认格式；
- 站点：Newgrounds（1995 起）、Kongregate（2006）等英文平台；中文的 4399/7k7k 等（详见 07）；
- 日常形态：开场动画、"Loading…"进度条、鼠标跟随小游戏、贺卡站——Flash 是千禧网页美学的"会动的那一半"；
- 终点与抢救：Adobe 于 2020-12-31 终止支持；社区抢救项目（如 Flashpoint 存档计划）在 2020 年代持续保存 Flash 游戏——与 GeoCities 抢救同属"数字公共考古"（见 04 篇）。

## 四、影视音乐与游戏（氛围层）

- **千禧流行乐视觉**：1998—2003 年间的镀铬舞台与银色宇航服式造型（如布兰妮、超级男孩等千禧流行 MV，泛化点名）；"2000 年人"造型是 Y2K 词条的时尚母本；
- **电影**：《黑客帝国》（1999）的数码雨与绿色终端常被误收进 Y2K 讨论——它更接近赛博朋克（主卷 15），但共享同一时期的电脑美学；广告与片头（约 1998—2005 的"数字未来"CG 风格）是更典型的 Y2K 影像；
- **游戏**：PS2 世代界面（2000—2005）；《第二人生》（2003）式的虚拟世界乌托邦是"数字未来"的叙事面；中文网游（《传奇》《泡泡堂》等）详见 07；
- **音景**：启动音与系统音（XP 的启动音、Vista 的"水银"音效、Wii 的开机音）构成"听得见的界面"——声音考古是千禧美学的冷门但高回报方向（本卷存目，未展开）。

## 五、档案、抢救与再创作（"出土"现场）

- **Archive Team**：GeoCities 抢救（2009-04—2009-10-26）；此后持续抢救各类濒死平台；
- **Internet Archive / Wayback Machine**：GeoCities 深爬（2009）与日常网页存档；"回到过去"的公共入口；
- **Neocities（2013）**：允许今天的人重建"1996 年的家"——网页 1.0 美学的活体实践；
- **Flashpoint**：Flash 游戏与动画的社区存档计划（2020 年代活跃）；
- **词条库作为活档案**：CARI（cari.institute）、Aesthetics Wiki 本身即是"分类—展示—消费"三合一的博物馆；Reddit 等平台的考古帖（"what was this website"）构成大众版网页考古。
