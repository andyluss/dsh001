> 本卷按太阳朋克附录卷（doc/retro-futurism/附录_太阳朋克卷/）同套流程编制（原独立成卷于 doc/y2k-aesthetics/，2026-09 并入主卷）：系统记录"千禧年互联网美学"——约 1995—2010 年间以数字生活乐观主义为底色的视觉系谱（Y2K 美学、Frutiger Aero、Webcore/网页 1.0 美学等）及其 2010 年代末以来的复兴与词条化——的概念、历史、家族、机制、作品、批评、中文语境与资料。优先体系化，余量以资料库兜底，引述尽量附来源。

## 与主卷（doc/retro-futurism/）的关系

- 主卷 17 蒸汽波篇、18 千禧篇已就"千禧数字美学"做过概述；本卷把整个**千禧-互联网美学家族**当作独立调研对象做正面深挖，卷首 `00_对读篇` 负责与复古未来主义的系统对读；
- 术语与主卷一致（主译名「Y2K 美学」「Frutiger Aero」等照英文通行；中文环境惯用英文原词，详见本卷 07 中文语境篇）；
- 本卷已并入主卷目录为**外编附录**（`附录_千禧美学卷/`，2026-09）；交叉引用按主卷篇号书写，如（见主卷 18 千禧篇）（见主卷 16 末日篇）；主卷 README"外编附录"节收录本目录。
