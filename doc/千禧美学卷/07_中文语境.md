# 千禧互联网美学 · 中文语境

> 关键词：Y2K 美学；中文译名；QQ 空间；网吧；4399；非主流；中文词条化
>
> 摘要：中文世界的千禧互联网美学有两条不同的记忆线：一条是"译介+标签"线（小红书 Y2K、知乎/B 站的词条化讨论），一条是"本土物件"线（网吧、QQ 空间、4399、QQ 宠物、非主流/杀马特）。本篇整理译名现状、本土记忆清单与中文词条化生态，并说明它与主卷 11 中国篇、18 千禧篇及本附录其他篇的分工。

## 一、译名与标签现状

| 术语 | 中文用法 | 说明 |
| --- | --- | --- |
| Y2K 美学 | 直接保留 "Y2K"（小红书/知乎/B 站话题），或写作"千禧美学/Y2K 风" | "千年虫美学"译法不准确（千年虫指 bug 本身），本卷不用 |
| Frutiger Aero | 无统一译名：直接用英文，或用"玻璃拟物/水滴绿叶界面美学"等描述 | 中文网络讨论多沿用英文原名 |
| Webcore / 网页 1.0 | "网页 1.0 美学/复古网页/个人主页美学" | 描述性译法 |
| McBling | 少见于中文；随 Y2K 泛化讨论进入 | 通常并入"2000s 复古"话题 |

中文网络词条化生态与英文不同：核心载体是**小红书话题、知乎问答、B 站考古视频与百度百科**，而非 CARI/Aesthetics Wiki；但"标签先行、语境后补"的结构一致（机制见 04 篇）。

## 二、本土记忆清单（中文"千禧互联网"的物件层）

| 物件/现象 | 大致时段 | 在美学谱系中的位置 |
| --- | --- | --- |
| 网吧与"冲浪" | 1990s 末—2010s | 中文 Web 1.0 的第一现场（"网络生存 72 小时"1999 实验是其寓言，见主卷 11） |
| OICQ/QQ（1999 前后） | 1999 起 | 中文即时通讯图腾；QQ 秀（约 2003）＝最早的中文"虚拟形象 DIY" |
| QQ 空间（Qzone） | 约 2005 起 | **中文个人主页第二春**：背景乐、挂件、相册、黄钻皮肤——中文版 GeoCities+MySpace 的合体 |
| 4399 / 7k7k 等 Flash 小游戏 | 约 2004 起 | Flash 一代的中文客厅（2020 年 Flash 终止支持后成为集体记忆现场） |
| 校内网→人人网（2005/2009） | 2005 起 | "实名社交"前夜；后来的衰落是中文数字废墟的著名案例 |
| 火星文与"非主流" | 约 2007—2009 | 青年亚文化对"个人表达"的极端化；与美式 Y2K 无直接血缘，但同属"千禧个人网络表达"谱系（杀马特为其后声，2020 年前后经纪录片等重新讨论） |
| 门户时代广告与"信息高速公路"宣传画 | 1990s—2000s | 主卷 11 中国篇的"国家主导未来形象"在此与消费级互联网合流 |

## 三、中文千禧记忆的特征

1. **追赶型数字化**（呼应主卷 11 的"追赶型未来"）：中文互联网的"未来感"长期是"追赶已兑现的西方未来"——信息高速公路宣传画与网吧并行，官方叙事与草根体验交织；
2. **物件优先于风格**：中文语境里，"千禧互联网"首先是一串物件与场所（网吧、QQ、空间、4399），其次才是视觉风格——因此中文的 Y2K 怀旧往往是**场景考古**（找 QQ 空间老截图、复刻火星文），而非美式"mood board"式风格消费；
3. **平台命运即记忆**：QQ 空间虽未死但"被远离"（2017 年《中国青年报》文章标题即《被远离的 QQ 空间里埋藏着最珍贵的过去》）；人人网衰落、4399 的 Flash 游戏集体作古——中文数字废墟的清单与英文世界（GeoCities、Flash）几乎同时发生，但以平台而非主机为核心。

- 主卷 18 千禧篇：已就 Y2K/Frutiger Aero/Webcore 做过**概述**，并专节写过"中国的千禧记忆"；
- 本卷 07（本篇）：深化**中文物件与场所考古**（QQ 空间、网吧、4399 等），不与主卷 18 重复铺陈同一批词条；
- 本卷 00—06：把美式词条框架讲透，供中文读者按图索骥对照本土记忆；
