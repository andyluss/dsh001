## 定位

本卷的调研对象不是核史本身，而是"人们如何想象原子的未来、又如何回望这份想象"：前一半是**第一序 · 档案**（当年的原子广告、民防海报与原子玩具），后一半是**第二序仿作与第三序混血**（从 1980 年代的原子考古纪录片到《辐射》系列与约 2008 年的命名）。按三层时间模型，本卷站在 T₂ 向后考古（见主卷 00 总论）。

与主卷的分工：主卷 08 原子篇做"原子纪"的时代考古（进步叙事、双面未来）；09 太空篇给出 Googie、射线枪哥特等术语；16 末日篇处理核末日与《辐射》详析；10 红旗篇提供苏联平行叙事。本卷以"原子朋克"这个**回望标签本身**为线索，把散落主卷各篇的素材收拢成定义、年表与视觉三份档案，交叉引用按篇号书写，如（见主卷 08 原子篇）。本目录现独立成卷于 doc/atompunk/。
