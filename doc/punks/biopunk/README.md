> 摘要：本卷是中文语境针对"生物朋克"的首次系统化资料整理，含对读、定义谱系、历史年表与美学四篇正文及本索引。卷内先交代命名史缺乏公认定论的现状；因证据薄弱处极多，全卷按"约/一般认为/存疑"降档行文，宁缺毋滥、严禁编造。

## 一、定位与缘起

**生物朋克（Biopunk）**指以基因工程、湿件等生物技术为底座、延续赛博朋克"高科技低生活"基调的朋克系文类（定义见 01）。与蒸汽朋克等"回望型"支系不同，它把生物学当下外推为近未来，不从"过去的未来"取材；故在《复古未来主义论文集》主卷的朋克谱系表上仅占一行（主卷 12 谱系篇："1990 年代科幻圈已见用例，词源存疑"），无专篇。本卷即补此缺，先在 doc/biopunk/ 独立成稿。

## 二、命名史现状：缺乏公认定论

蒸汽朋克一般认为有 1987 年可考用例作命名原点；**biopunk 却无公认原点**：先行词 ribofunk 归于保罗·迪菲利波（同名结集一般认为 1996 年前后，存疑），biopunk 约在 1990 年代末至 2000 年代经网络社群与盘点清单流通（存疑）。本卷存疑标注密度较高，引用请连带标注。
