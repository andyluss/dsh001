## 一、卷定位

本卷记录柴油朋克——回望"柴油纪"（约 1918—1945 年，延伸至 1950 年代初）的复古未来文类与美学。与《复古未来主义论文集》（doc/retro-futurism/）以"考古战间真实档案"为主的写法不同，本卷把**回望动作本身**当作对象：术语从何而来、作品何时成批出现、美学由哪些元素构成、为何这一支复古最容易滑向历史本身。全卷不重复档案细节，凡战间实物与图像细节一律指引回主卷对应篇目。

## 二、与主卷 07、12 的关系

- 主卷 **07《战间篇·柴油朋克》**考古的是第一序档案：兴登堡号、巴克·罗杰斯与飞侠哥顿、1939 年纽约世博会"未来世界"馆、法西斯纪念碑建筑——战间期真实生产过的未来图像。柴油朋克的"本体"在彼处；
- 主卷 **12《谱系篇·朋克宇宙学》**给出术语考据与谱系坐标：柴油朋克命名年代（一般认为约 2001，属追溯命名）、四元素配方、与蒸汽/原子/装饰朋克的边界关系；
- 本卷与两篇**错位互补、不重复**：07 是"货源档案"，12 是"地图一格"，本卷是围绕柴油朋克这一标签的专题纵深——定义与谱系、双栏编年、美学语法与自我审视。交叉引用统一写作"（见主卷 07）""（见主卷 12）"，以主卷篇号为准。
