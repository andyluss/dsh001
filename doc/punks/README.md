## 一、定位与缘起

doc/punks/ 收纳五个以"××朋克"为主题的**独立研究卷**（曾分别位于 doc/ 顶层，2026-09 统一迁入本目录）。各卷均由子代理成稿，内容自成体系：卷首"00_对读篇"以《复古未来主义论文集》的框架做对照思考，但正文不依赖主卷即可阅读；与主卷体系是否并入、何时并入，另行决定。
